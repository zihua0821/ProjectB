## 1. 背景与目标

### 1.1 现状痛点（实测修正版）

《星语》项目中，Cell 轮廓、Plot 地块、Crop 作物三大系统通过 ISM 渲染 **6~7 万活跃作物实例**（地块 S2 与作物 S3 为同一单元格网格的两个渲染层，各自 6~7 万实例，合计渲染 ~12~14 万）。分桶对照实验（FarmlandActor A/B/C/D）暴露的真实瓶颈：

1. **渲染线程提交瓶颈**：draw 成本 ∝ 提交实例数。7 万实例单桶全提交时渲染线程 draw **27ms**（实验 A），远超 16.6ms 帧预算——这是第一瓶颈；
2. **组件级剔除失效**：离散分布实例 → 组件包围盒 ≈ 整体 AABB → 视锥/距离剔除失效 → GPU 全绘制 **23ms**（实验 A）；
3. **实例索引不稳定**：`RemoveAtSwap` 重排导致索引型句柄失效，业务侧无法安全持有实例引用；
4. **非增量路径全量重建**：每次修改触发组件级 `MarkRenderStateDirty` → GPU Scene 全量重建，实例越多越不可承受；
5. **空间语义混乱**（P1 历史遗留）：部分路径世界/局部空间混用，组件 Transform 非单位时渲染错位。

**重构目标**：空间分桶 + 引擎原生增量 API，以引擎 5.5.4 原生 ID/增量管线为基座，支持压力场景（6~7 万活跃实例 @60fps）与远期更大规模（50 万 @30fps）。

### 1.2 架构决策（2026-08-07 定稿）

| 编号 | 决策 | 内容 |
|------|------|------|
| D-1 | **空间分桶（位置判据）** | 桶 = 连续空间区块（平面 N×N / 球面经纬块，可插拔映射层）；组件 = 唯一网格体 × 区块；**分桶判据 = 实例实际位置**（空间划分，非"桶满才分裂"的容量分桶）；分桶使包围盒紧凑，视锥/距离剔除生效；**块大小由每桶最大实例数量推导**（每块覆盖 ≤ 2048 个格子，密铺时每桶 ≤ 2048），桶数随星球网格自适应总单元格数量 |
| D-2 | **引擎原生增量 API** | `bUseIncrementalISM=true` + `AddInstancesById` / `RemoveInstancesById` / `SetCustomDataValueById`，O(1) 增量提交，无需自研脏队列/Flush |
| D-3 | **外部管理器承载分桶** | 扩展 `UISMManager`（WorldSubsystem）：持有桶映射层 + 组件表（MeshIdx × BucketIdx → 组件）；不写自定义 ISM 组件、不复制引擎代码、不继承引擎类 |
| D-4 | **取消实例级透明池化** | 原生 API 自带 free list 槽位复用；仅保留组件级池化（空桶常驻不销毁），避免运行期组件创建抖动 |
| D-5 | **懒创建** | `GetOrCreate` 语义：组件/桶按需创建，不预初始化全量空组件 |
| D-6 | **稳定句柄** | `FGlobalInstanceId` = (BucketIndex, `FPrimitiveInstanceId`)，对外屏蔽物理索引，Remove 后失效可检测 |

### 1.3 决策依据（实测背书）

| 证据 | 数据 |
|------|------|
| 分桶收益 | 实验 A（BPA=1）36fps → B/C（BPA=5/8）64fps（fps **+78%**，帧时间 27.8→15.6ms 即 -44%）；收益机制 = 渲染线程提交量 7 万 → ~2 万 |
| 原生增量成本 | 引擎原生 ID API ~0.35μs/调用；106 切换/帧实测 **0.232ms**；583 切换/帧实测 **~1.3ms** |
| 稳态 tick | 7 万实例 + 306 变更/帧，游戏线程 tick 仅 **0.35ms** |
| 组件规模无压力 | C 实验 5120 组件 64.2fps；每帧空组件相关性判断 0.1~0.3μs/组件 |
| Nanite 协同 | Nanite 逐实例剔除只救 GPU（23→14ms），渲染线程提交成本不变 → **分桶仍然必需** |
| 测试模式背书 | A/B/C/D 实验本身就是"外部管理分桶 + 原生组件"模式，结论直接背书 D-3 |

## 3. 压力场景量化模型（已确认边界）

### 3.1 输入参数（用户确认，不变）

| 参数 | 值 |
|------|-----|
| 活跃单元格（作物实例） | 60k ~ 70k |
| 同时可见 | 最多约 1/3（2 万 ~ 2.3 万，GPU 剔除） |
| 作物种类 / 每阶段网格体 | ~20 种 × 4 阶段 ≈ 80 网格体 |
| 阶段时长 | **不固定，2 ~ 20 秒区间**（平均按 11s 估算） |
| 测试循环 | 随机作物随机阶段开始 → 依次走完 4 阶段 → 换随机作物从头开始 |
| 初始相位 | **确定随机化**（避免 20 秒同步突发尖峰） |
| 帧率档位 | 当前量级 60fps（硬要求）；远期更大规模 30fps 可接受 |
| 切换语义 | 阶段变化 = 旧网格体组件 Remove + 新网格体组件 Add（跨组件迁移） |

### 3.2 派生指标

**每实例切换率** = 4 次 / (4 × 阶段时长)：

| 档位 | 阶段时长 | 每实例切换率 | 70k 每秒切换 | 60fps 每帧切换 | 30fps 每帧切换 |
|------|----------|--------------|--------------|----------------|----------------|
| 平均档 | 11s | 0.0909/s | ~6,364 | **~106** | ~212 |
| 极端档（全最短） | 2s | 0.5/s | 35,000 | **~583** | ~1,166 |

**组件操作**（每次切换 = 1 Remove + 1 Add，×2）：

| 档位 | 每帧组件操作（60fps） | 每组件每帧（÷2836 桶组件） | 泊松 P99 峰值/帧 |
|------|----------------------|---------------------------|------------------|
| 平均档 | ~212 | ~0.075 | ~130 切换 |
| 极端档 | ~1,166 | ~0.41 | ~640 切换 |

**组件（桶）分布（v2.5 定稿：空间划分 + 单参数）**：

| 参数/推导 | 值 |
|-----------|-----|
| **每桶最大实例数量（唯一参数）** | **2048**（`INSTANCES_PER_BUCKET`）：**参与空间划分**——块大小 = 覆盖 ≤ 2048 个格子的连续格子块（密铺时每桶 ≤ 2048）；同时是容量保险（防极端聚集） |
| 桶划分（空间结构） | 经纬块 = 星球网格连续格子块，**块大小按每桶最大实例数量推导**（每块覆盖 ≤ 2048 个格子）；桶数 = ceil(LatCells/LatBlockSize) × ceil(LonCells/LonBlockSize)，**随星球网格适配** |
| 桶数量级示例 | 70k 网格按每块 ≤ 2048 格子划分 → **~35 桶**（BPA≈6 量级，与实验 B/C 同区间）；密铺时每桶 ≈ 2048（上限），离散时实际数量 = 分布结果 |

| 系统 | 计算 | 组件数 |
|------|------|--------|
| S3 作物 | ~35 桶 × 80 网格体（懒创建，实际 = 有实例的桶） | ~2800（上界） |
| S2 地块 | ~35 桶 × 1 网格体 | ~35 |
| S1 轮廓 | 单桶 | 1 |
| **合计** | | **~2836（≤ 4000 ✓）** |

> 粒度推导（v2.5）：**块大小由每桶最大实例数量（2048）推导**——每块覆盖 ≤ 2048 个格子 → 密铺时每桶 ≤ 2048 实例，离散时实际数量远小于上限；桶数 = 网格划分结果（示例 ~35 桶，弧长 ~2~2.5km，与实验 B/C 的 BPA=5/8 同量级），随星球网格规模自适应。组件上界 ~2836（35 桶 × 81）→ 处于 C 实验 5120 组件背书区间内，**渲染线程 primitive 遍历风险解除**（OQ-6）；空桶停用采用**事件驱动**（Remove 归零即停用，无每帧轮询）。远期 50 万：**网格分辨率每轴翻倍（总面积 ×4）** → 桶数 ~4 倍（~140 桶）→ 组件上界 ~11300，需实测。

> 参数模型（v2.5，用户定稿）：**分桶判据 = 实例实际位置**（空间分桶，永不"桶满才分裂"）；**唯一参数 = 每桶最大实例数量（2048）**——**参与空间划分**：块大小 = 覆盖 ≤ 2048 个格子的连续格子块，确保一个空间矩形（桶）密铺时最多容纳 2048 个实例；同时是容量保险。**实际每桶数量 = 空间分布自然结果**——密铺 ≈ 2048（上限），离散时远小于上限。**均匀密铺与离散统一使用同一套空间分桶逻辑**（实验 B/C 的 BPA 划分即此逻辑，结论可迁移）。

**每帧变动组件数（v2.5：按桶组件计，示例划分）**：
- 平均档：212 操作/帧分散到 ~2836 个桶组件（每组件 λ≈0.075），操作去重后**每帧变动 ~205 个组件**；
- 极端档：1166 操作/帧 → 按去重期望 N(1-e^(-k/N)) 计算**每帧变动 ~960 个组件**（P99 峰值帧 ~1030；引擎原生 ById API 逐操作提交，无需批量化 Flush）。

### 3.3 关键结论（实测版更新）

1. **稳态 106 切换/帧对引擎原生 API 完全可行**：实测 0.232ms/帧，远低于预算 ✔；
2. **极端档 583 切换/帧为设计上限**：实测 ~1.3ms，60fps 预算内 ✔；30fps 远期档（1166/帧）按比例外推；
3. **瓶颈是渲染线程 + GPU 的提交/绘制量，不是游戏线程**：draw 27ms > GPU 23ms，均 ∝ 可见实例数；分桶双管齐下；
4. **分桶收益机制**：提交实例数 7 万 → ~2 万（B/C 64fps vs A 36fps），组件包围盒缩小让视锥/距离剔除生效；
5. **Nanite 不能替代分桶**：GPU 端逐实例剔除生效（23→14ms），渲染线程提交成本不变；
6. **池化动机消失**：原生 Add/Remove O(1) 增量 + 引擎内建 free list 复用槽位，实例级透明池化带来的包围盒膨胀/跨组件无效等负担不再必要；
7. **初始随机相位是硬性前提**：若同步开始，每个阶段结束时（阶段时长 2~20s，平均 11s）6~7 万实例同步突发切换，数量级不可承受；
8. **球面分桶必须规避经度回绕**：桶列边界对齐 0° 经线，防止包围盒跨圈撑爆（FR-6）。

## 4. 功能需求

| 编号 | 需求 | 说明 |
|------|------|------|
| FR-1 | 统一批量接口 | `BatchAddInstances` / `BatchRemoveInstances` / `BatchSetInstanceCustomData` / `UpdateInstanceCustomData` 对 S1/S2/S3 一致，调用方不感知桶 |
| FR-2 | 空间分桶（位置判据） | 桶 = 空间区块（平面 N×N / 球面经纬块可插拔映射层）；组件 = Mesh × Bucket；**分桶按实例实际位置**（非容量满桶分裂），密铺/离散统一；分桶透明 |
| FR-3 | 稳定句柄 | `FGlobalInstanceId`（BucketIndex + `FPrimitiveInstanceId`）在实例存活期内稳定；Remove 后 `IsValid()=false` 可检测 |
| FR-4 | 引擎原生增量 | `bUseIncrementalISM=true`；增删/改 CustomData 全部走 ById 增量路径，不触发组件级全量 `MarkRenderStateDirty` |
| FR-5 | 懒创建 + 组件级池化 | `GetOrCreate` 按需创建组件/桶；空桶常驻复用（组件级池化），避免运行期组件创建/销毁抖动 |
| FR-6 | 球面经纬块分桶（位置判据） | 桶 = 连续经纬网格区域块，映射 `BucketIdx = (LatIdx/LatBlockSize) * LonBlockNum + (LonIdx/LonBlockSize)` 为 O(1)；**分桶判据 = 实例实际位置**（非容量满桶分裂）；**经纬块 = 星球网格连续格子块，块大小按每桶最大实例数量推导**（每块覆盖 ≤ 2048 个格子，密铺时每桶 ≤ 2048）；桶数随星球网格适配；桶列边界对齐 0° 经线 |
| FR-7 | 单参数配置 | **唯一参数 = 每桶最大实例数量（2048 = `INSTANCES_PER_BUCKET`）**：①**参与空间划分**——块大小按每桶 2048 实例推导（每块覆盖 ≤ 2048 个格子，密铺时每桶 ≤ 2048）；②容量保险（防极端聚集）；实际每桶数量 = 分布结果；`BucketingThreshold` 保留为兼容开关 |
| FR-8 | 突发批量承受 | 单帧 583~数万实例全量种植/收获/重种不卡顿（极端档 583 切换/帧 → 测试台全图重置突发数万） |
| FR-9 | 高频阶段切换 | 压力场景核心路径：平均 106 / 极端 583 切换/帧的跨组件迁移（Remove + Add），句柄替换原子化 |
| FR-10 | CustomData 语义保持 | CustomData[0]=Opacity（材质依赖，隐藏策略基石）；Disease=1 / IsLeaf=2 索引不破坏 |
| FR-11 | 句柄有效性检测 | 遵循引擎原生 `FPrimitiveInstanceId` 语义（Remove 即失效），调用方不持有已删句柄 |
| FR-12 | 旧调用方迁移 | `CropManagerComponent` 三处遗留 TODO 迁移至 ISMManager 接口（见 §9） |
| FR-13 | 空间语义统一 | ISM 挂 ISMRoot 原点、实例使用世界坐标；`BatchAddInstances` 世界空间输入约定 |

| PR-9 | 渲染侧 | 可见 ~2.3 万实例；GPU 增量缓冲更新量 = 脏实例数，不随总实例数线性放大 |
