## 一、测试目标（四维度）

```
① 耐力：30min+ 长跑——稳态保持（工作产出、漂移不累积、无性能退化）
② 规模：多轨道（≥2 轨，每轨 8~10 星）——跨轨独立规划互不干扰
③ 密度：密集农田（连片）+ 稀疏区——选点/覆盖带/饥饿行为
④ 编辑回归：运行中编辑轨道（ApplyOrbitChanges）——槽重建/相位对齐/认领
```

## 五、日志与观测准备（已核对，2026-09-30）

```
功能日志（Log 级，常开）：
  [SatelliteTask] Entity[N] work start at cell (x, y) (轨道名), items=…     ← 分轨 work 计数
  [SatelliteTask] Entity[N] Drift start/complete (move=…°)                  ← 漂移行为
  [SatelliteTask] Entity[N] Drift interrupted for work at cell (x, y)       ← 中断计数
  [SatelliteTask] Entity[N] Approach arrived / work complete / Return …     ← 链路
  [OrbitPlan] Entity[N] drift to slot S (轨道名) / assign return slot S (轨道名)  ← 分轨规划
  [SatelliteManager] Applied orbit changes: N satellites on M orbit(s)      ← R4 重建时刻
告警（Warning 级，常开）：
  [OrbitPlan] claim failed（认领冲突/幽灵检测）
  [SatelliteTask] DepartWait waiting >10s（长等待）
探针（Verbose 级，默认静默）：
  interrupt->Depart delivered in X ms（中断送达延迟——核验卡死链）
  reuse claimed target（兜底路径——理应全程 0 次）
开启方法：控制台 `log LogTemp Verbose`；收回：`log LogTemp Display`
```

**统计命令（归档日志后执行）**：
```powershell
$f='F:\UEProjects\ProjectB\Saved\LogTemp_R1.txt'; $l=Get-Content $f -Encoding UTF8; 'lines:'+$l.Count
$m=[int]($l.Count/2)
'前w='+($l[0..$m]|Select-String 'work start' -SimpleMatch).Count+' d='+($l[0..$m]|Select-String 'Drift start' -SimpleMatch).Count
'后w='+($l[$m..($l.Count-1)]|Select-String 'work start' -SimpleMatch).Count+' d='+($l[$m..($l.Count-1)]|Select-String 'Drift start' -SimpleMatch).Count
foreach($p in 'Drift interrupted','delivered in','waiting >10s','reuse claimed target','claim failed','Warning','Error'){ $p+' : '+(Select-String -Path $f -Pattern $p -SimpleMatch -Encoding UTF8).Count }
# R2 分轨：把 'work start' 换成 '(轨道名)' 或按 [OrbitPlan] 行分轨统计
```
