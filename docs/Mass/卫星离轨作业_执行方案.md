## 三、状态机改动（定稿：6 状态 + 两个专用等待任务）

```
现状：Cruise → MoveToTarget（沿轨道奔赴）→ Execute（在轨停驻作业）
目标：Cruise → Depart → Approach → Work → AwaitReturn → Return → Cruise
```

| 状态 | 承载任务 | 职责 |
|---|---|---|
| Cruise | `FSatelliteSelectTargetTask`（改造·合并） | 巡航 + 选点 + **调用构建函数**（一次产出 TargetCoord + WorkQueue；新增：ω≈0 跳过） |
| **Depart**（待发） | **`FSatelliteDepartWaitTask`（新增·专用）** | 判定"最近点"时机 → Success；不控制运动（继续巡航） |
| Approach | `FSatelliteMoveToTargetTask`（改造） | 贝塞尔飞向悬停点（位置覆盖） |
| Work | `FSatelliteExecuteActionTask`（改造） | 悬停 + **格内操作队列依次执行**（每项时长；每个 action 前所有权检查）+ 释放 |
| **AwaitReturn**（待回） | **`FSatelliteReturnWaitTask`（新增·专用）** | 判定"虚拟相位点最近点"时机 → Success；保持悬停 |
| Return | `FSatelliteReturnTask`（新增） | 贝塞尔飞回入轨点（清位置覆盖） |

**说明**：
- **状态写入**：各任务在 EnterState 时将对应状态写入 fragment（`FMassOrbitFragment::State`）——调试可见、处理器可读
- 原 `MoveToTarget`（沿轨奔赴）语义不再使用——改造复用为 **Approach（离轨飞行）**
- **中断规则（已确认）**：选定目标（占有）后，在每个状态转换点做所有权检查；失去所有权 → 取消当前任务、跳到规定状态：
    · Depart → Approach 转换时失权 → **回 Cruise**
    · Approach → Work 转换时失权 → **直接跳 AwaitReturn**（已在悬停点）
    · Work 期间：**每个 action 前**检查，失权 → **跳 AwaitReturn**
  （规则在状态树资产中配置；所有权检查 = 已认领 Slot/句柄的有效性）
- 原"三选一"方案已作废（6 状态结构经拍板采纳）


## 四、路径算法（AI 负责实现；轨道校验已搁置）

### 4.1 悬停点（`ComputeOrbitHoverPoint`；每次现算，不落存储）
```
H = S + Normalize(S) * HoverHeight
  S = Normalize(CellCenter) * PlanetRadius   // 格子中心投影到球面
  HoverHeight 来自 PlanetConfigDataAsset（星球配置）
```

### 4.2 最近点判据（`IsAtNearestPhase`；已确认：行动时机）
```
PhaseDir  = 当前相位点在轨道平面内的径向方向（单位向量）
TargetDir = 目标/悬停点在轨道平面的径向方向（投影后归一化）
判据：Dot(PhaseDir, TargetDir) ≥ cos(容差角度)（建议容差 2°）
应用：离轨 Wait = 等目标最近点；回轨 Wait = 等虚拟相位点的最近点
```

### 4.3 三次贝塞尔路径（已确认：k = 0.35）
```
求值（EvaluateCubicBezier）：
   B(t) = (1-t)³P0 + 3(1-t)²t·P1 + 3(1-t)t²·P2 + t³P3（t 经 smoothstep）
控制点组装（BuildOrbitTransferControlPoints）：
   离轨：P1 = P0 + 轨道切线 × d；P2 = P3 + Normalize(P3) × d
   回轨：P1 = P0 + Normalize(P0) × d；P2 = P3 + 轨道切线 × d
   d = k × |P0 → P3|（k 存于卫星管理组件统一配置，默认 0.35）
轨道切线（ComputeOrbitTangent）：由参数化 (R·cosθ, R·sinθ, 0) 的导数导出（含顺逆时针正负）
采样校验（ValidateTransferPath）：16 点采样，min|P| ≥ 悬停层 - 1cm
飞行速度（已确认）：v = ω(rad/s) × R_orb（轨道线速度，无参数）；时长 = 路径长度 / v
路径近似长度 = |P0→P1| + |P1→P2| + |P2→P3|
ω≈0（已确认·选 b）：该轨道卫星不参与作业——选点阶段跳过
```

### 4.4 轨道有效性校验（**已搁置**——后续独立需求，本轮不做）
```
（公式保留备查）：轨道圆最低点到球心距离 D_min = | ‖Center‖ − OrbitRadius |
有效条件：D_min > PlanetRadius + HoverHeight（HoverHeight 来自星球配置）
未来落地：轨道管理组件（UOrbitManagerComponent）提供校验，轨道编辑面板联动提示
```

## 五、移动与渲染同步（数据流定稿）

```
角度（虚拟相位）：
  · Depart / Approach / Work / AwaitReturn / Return 全程，轨道角度按 ω 照常推进
  · 写入 VirtualPhase 字段（显式记录；巡航时与当前角度一致）
位置（三类来源，由状态决定）：
  · Cruise / Depart：位置 = 轨道角度算得（现状机制，无覆盖）
  · Approach / Return：任务每帧：位置 = 贝塞尔求值 → 写 bOverrideLocation=true + OverrideLocation

          飞行期间每帧仅做曲线求值（~30 flops，无需预采样路径点）
  · Work / AwaitReturn：进入时写一次（= 悬停点），之后保持（无任务写入即维持上一值）

  · 飞行结束（PhaseElapsed ≥ PhaseDuration）：写精确终点 → 状态切换（状态树转换）
  · 回轨完成：清 bOverrideLocation → 位置由角度接管（同一相位 → 连续无跳变）
实现注意：MovementProcessor 移除旧 MoveState 分支（Idle/MovingToTarget/Paused），
           统一为“角度按 ω 推进”（巡航与离轨期间行为一致——离轨时仅位置被覆盖）
```

### 11.2 参数（已确认：单参数 v_r，两段共用；配置于卫星管理组件）

```
v_r（转场径向速度，默认 2000 cm/s）—— 唯一配置参数
  位置：SatelliteManagerComponent 细节面板（Category "Satellite"，字段 RadialTransferSpeed）
  读取：SatelliteManager::GetRadialTransferSpeed()（与 TransferControlFactor 同层）
T = |R_orb − R_hover| / v_r（离轨/回轨共用，T 相同；例 4000/2000 = 2.0 s）
切向：角速度恒 = ω；切向推进量 = ω·T（例 10°/s × 2s = 20°）
回轨时机：θ_当前 = θ_hover（悬停投影 ↔ 槽位重合，容差小值）
离轨时机：θ_当前 = θ_hover − ω·T·dir（精确提前量）
```

### 11.3 验收

```
· 回轨落点 = θ_hover + ω·T 对应的轨道点（无需预测、无迭代，与实测一致）
· 汇入处角速度与轨道一致（无顿挫/无跳变）
· 多星同轨无追尾（相对角位置恒定）
· 无"等很久"（立即起飞）
· 路径可视化：参数方程采样与实飞轨迹重合
```

### 11.4 与旧实现的关系

```
· 保留：六状态机 / 队列 / 认领机制 / 位置覆盖 / 槽位（逻辑登记）
· 替换：仅"路径构造与求值"（贝塞尔 → 极坐标同步插值）
· 移除：选槽三条件 / 路径校验 / 控制点封顶（均为贝塞尔专用）
```

### 11.5 槽位查询改为【按认领句柄】（单一事实源）

```
背景：曾同时维护 "槽索引(int32) + 认领句柄(FSmartObjectClaimHandle)" 两个字段，
      一旦二者生命周期不同步就会出问题（实测：回轨到达时清了索引但未清句柄 → 渲染回退
      到账面相位点 → 位置跳变 4.8° ≈ 4600cm）

设计：fragment 只保留认领句柄；已认领后的槽位查询一律用它
  · 新增：GetOrbitSlotWorldPositionByClaim / GetOrbitSlotPhaseByClaim / ResolveSlotIndexByClaim
        （内部按 SlotHandle 反查槽索引：IndexOfByKey，量级 = 卫星数，极廉）
  · 保留：按索引查询三个接口（仅用于"选槽遍历"——此时尚未持有句柄）
  · 删除：FMassOrbitFragment::ClaimedSlotIndex
  · 生命周期：认领时写句柄；离轨让槽 / 回轨到达后释放时清句柄

收益："双字段不同步"类缺陷结构上不可能再发生；索引仅作为调试可读性由反查得到
```
