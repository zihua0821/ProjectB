## 二、架构设计

### 2.1 两层结构

```
【群体层】轨道规划（卫星管理器内，轻量）
    Tick 节流到点 → ①抄账（CollectOrbitSnapshot）→ ②求解（BuildOrbitPlan，纯函数）→ ③发单（DispatchOrbitPlan）
【个体层】六状态机（+Drift）——执行动作，职责不变
    Cruise：消费漂移指令 → Drift；ReturnWait：消费已认领的槽（等重合起飞）
    （转移条件仍全部显式在状态树资产中）
```

**关键原则**（延续项目既有约定）：
- 求解函数**无状态、确定性**：不缓存旧账，同一快照必得同一计划；排序平局一律用显式键（序号），杜绝"谁先算/何时算"影响结果
- **占位地图单一来源**：某星占位 = 其 `SlotClaimHandle` 所指的槽；在途星句柄即目标槽（"在途当已到"由句柄天然表达，不新增"在途字段"）
- 计划为派生物：消费即弃，随时可重算

### 2.2 数据流（滚动节拍）

```
发单后不等待执行：下一轮到点时，在途星已被句柄按"目标槽"计入快照
→ 天然消解"等完成"阶段，无 Monitoring 状态，无超时处理
```

### 2.3 发单的三类动作（Dispatch 侧，非纯函数）

| 动作 | 执行内容 | 说明 |
|---|---|---|
| `AssignReturnSlot` | `TryClaimOrbitSlot(目标槽)` → 成功则写回星句柄 | 待返星原无槽，认领即完成；ReturnWait 只需等句柄出现 |
| `DriftToSlot` | ① 认领目标槽 B（失败则跳过）→ ② 写星数据：句柄=B、`bDriftRequested=true`、**冻结显示**（`bOverrideLocation=true` + `OverrideLocation=当前显示位置`）→ ③ 释放旧槽 A | "冻结"防止句柄切换帧渲染瞬移（帧序安全）；③ 后系统状态完全一致 |
| （无动作） | 不写任何数据 | |

> 冻结后到星启动漂移之间（1~2 帧）：显示停在旧位置（无感）；星启动后覆盖位置即开始滑动，接管连续。

## 三、求解器设计（纯函数）

### 3.1 快照结构（拟定，命名由 AI 定）

```cpp
struct FOrbitSnapshotEntry
{
    FMassEntityHandle Entity;
    int32 Ordinal;                      // 创建序号（确定性平局键）
    FSmartObjectClaimHandle SlotHandle; // 占位（无效=无占位：离轨/作业/待回）
    int32 SlotIndex;                    // 句柄反查的槽索引（-1=无）
    ESatelliteState State;
    bool bAwaitingReturn;               // 待返（在悬停等待分配）
    FVector HoverLocation;              // 待返星悬停点（等待成本计算用）
};

struct FOrbitSnapshot
{
    FName OrbitName;
    float SlotPhaseBaseDeg;             // 槽网格基准相位（抄账瞬间快照，保证同帧一致）
    float AngularVelocity;
    bool  bClockwise;
    float OrbitRadius;
    int32 SlotCount;                    // = 卫星数 × K
    TArray<FOrbitSnapshotEntry> Entries;
};
```

### 3.2 求解流程（两阶段近似：落点优先、均匀化次之）

```
阶段①【待返星落点分配】（必须落；乙案·已确认）
  候选 = 全部空槽中"等待角 ≤ 45°"者（等待角 = 槽到达该星悬停投影的剩余角）
  择选 = 取"插入后最小相邻间距最大"的候选；平局取等待角小者；再平局取序号小者
  分配方式：贪心（逐颗分配），分配后立即并入占位集合
  输出：AssignReturnSlot
  （待返星数极少，贪心足够）

阶段②【在轨均匀化】（闲着才挪）
  触发：当前"最小相邻间距" < 均匀间距 × 0.6
  对象 = 占位星中"在轨巡航、无在途指令"者（返航飞行中 / 在途漂移的星不动）
  目标构型：间隔 τ = 360 / N*（N* = 占位总数）
  试算锚：每颗星依次当"基准"→ 目标网格 = 锚相位 + k·τ → 各星映射最近网格位 → 总位移
  取总位移最小的锚方案 → 得到目标位；目标位映射到最近空槽（均匀位天然落在槽网格上）
  过滤：位移 < 3°（不值当）或 > 45°（与等待上限统一）不漂
  防撞（合并版·已确认）：新路线不得穿过他星占位；任何两段路线（含在途漂移的）区间重叠 → 后发者推迟下一轮
  输出：DriftToSlot
```

### 3.3 确定性规则（硬性）

```
· 所有候选排序键显式指定（评分相等 → 比位移 → 比序号）
· 快照一次性收集（同一函数内循环读完，不跨帧、不穿插查询）
· 求解不读取任何"上次调用"的残留（无缓存字段）
```

## 四、漂移执行设计（R4）

### 4.1 运动模型与参数（转场特例——删去径向/垂直分量）

```
通俗模型：加速前移（比轨道快、追赶前方目标位）/ 减速后移（比轨道慢、让目标位迎上来）；
          滑动速度差 = 1 倍轨道速度（滑行速度最高 2 倍轨道速度）；后移不得减速到倒车
起点：实测显示位置（有覆盖用覆盖，否则槽点）——与离轨起点的取法同款
目标：槽 B（起飞时刻相位 φB 实时读取）
参数（EnterState 一次算好）：
  Δs = FindDeltaAngleDegrees(θ_start, φB) · dir（有符号位移量：正=前移 / 负=后移；|Δs| ∈ [3°, 45°]）
  速度差 = 1 × ω；T = clamp(|Δs| / (1×ω), 2.0, 4.5) 秒（位移 45° → 4.5s；小位移自动放慢）
  后移约束：ω − |Δs|/T ≥ 0（不倒车）
  θ(α) = θ_start + (ω·T·dir + Δs)·α（与回轨同构的总切向增量）
Tick：α = t/T → 位置写覆盖（复用 ComputeOrbitWorldPosition）
落地：写落点 → VirtualPhase = 槽 B 相位（账面对齐）→ 清覆盖 → 清 bDriftRequested → State=Cruise
```

### 4.2 生命周期与边界

```
启动：Cruise 中发现 bDriftRequested → 转移至 Drift → EnterState（算参数、清标志）
中断：任何阶段任务选中 → 以"实测显示位置"为离轨起点直接离轨（同源原则）；
      让槽逻辑释放当前句柄（=B），回轨时由全局决策重新分配
落地：与回轨到达同款（写点→对齐相位→清覆盖），无跳变
```

### 4.3 参数（定稿）

```
等待上限 = 45°（排座过滤）              位移范围 = [3°, 45°]（上限与等待统一）
滑动速度差 = 1 倍轨道速度               时长 = clamp(位移 ÷ 速度差, 2.0, 4.5) 秒
规划节拍间隔 = 1.0s                     防撞 = 合并版（路线重叠 → 后发推迟一轮）
```

