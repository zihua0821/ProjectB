# 农业闭环_需求文档

> 卫星从"只收获"扩展为**全能农业执行者**：对活跃农田执行"缺什么补什么"的完整农事，成熟收获后自动重播。
> 本文档为需求层的定稿基线，设计/实施计划另见后续文档。

---

## 一、背景与目标

**现状**：卫星只做收获（发现成熟格子 → 认领 → 移动 → 收获）。

**目标**：卫星成为玩家规划的**全流程执行者**——对活跃农田完成全部农事维护，实现"玩家规划、卫星干活"的分工模式。

---

## 二、角色与分工

| 角色 | 职责 |
|---|---|
| **玩家** | 规划（划定种植区域——**本期不实现**）；可随时手动操作（与卫星共享认领协议，High 抢占已实现） |
| **卫星** | 对活跃农田执行全流程农事；主动发现目标并奔赴 |

---

## 三、工作集合：活跃农田（本期基准）

```
活跃农田 := 已耕地 且 已播种的格子（含已收获待重播）
    ├─ 播种（Crop Slot 启用）时进入集合
    └─ 移除作物/移除耕地时离开集合

不选择：未耕地 / 未播种的格子（不做开荒、不做空地播种）
```

**区域规划（后续）**：玩家划定区域后，工作集合 = 区域 ∩ 活跃农田（本期先做全图活跃农田）。

---

## 四、功能需求

### FR-1 操作覆盖（缺什么补什么）

卫星对目标格子的操作由**当前缺口**决定，操作集与判定依据：

| 缺口 | 操作 | 判定依据（直读 fragment） |
|---|---|---|
| 有杂草 | 除草 | `EPlotState::WeedInfested` |
| 有害虫 | 除虫 | `EPlotState::PestInfested` |
| 缺水 | 浇水 | 水分未满足（`1 - MoisturePercentage` 参与评分） |
| 缺肥 | 施肥 | 肥力未满足（`1 - FertilityPercentage` 参与评分） |
| 作物成熟 | 收获 | `CropGrowthStage == Mature` |
| 已收获待重播 | 重播 | `CropGrowthStage == Harvested` |

**多缺口并存时**：不设固定硬顺序，由**评分权重**决定优先级（见 FR-3，权重可配）。

### FR-2 收获与重播（闭环）

```
作物成熟 → 收获 → （格子保持活跃农田）→ 重播同类型作物（CropID 取格子作物数据）
```

- 重播作物：**同类型**（从格子已有作物数据 `FCropStaticConfigFragment.CropID` 读取）
- 重播后恢复生长循环（水/肥/草/虫维护继续）
- **实现方式待确认**（见第七节待确认点 1）

### FR-3 选点：EQS 评分规则迁移（权重 + 距离）

**迁移自旧 EQS 三段式**（生成 → 过滤 → 评分），本阶段"迁移完善"：

```
① 候选集 = 活跃农田（已耕地+已播种；含待重播）
② 过滤   = 在卫星轨道覆盖带内（几何判定，与旧"厚度"语义一致）
          + 存在实际缺口（无缺口的格子不产生目标）
③ 评分   = 状态权重（缺什么） + 距离权重（多远）
     状态项（越高越优先）：
        成熟待收   × HarvestWeight
        待重播     × ReplantWeight
        杂草       × WeedWeight
        虫害       × PestWeight
        (1-水分)   × MoistureWeight
        (1-肥力)   × FertilityWeight
     距离项：
        与卫星当前角度的角度差（越小越好） × DistanceWeight
        （轨道平面偏离约束：过远目标自然被距离项抑制）
④ 取最高分 → 认领对应 Slot → 移动（轨道角度）→ 作业 → 释放
```

**权重配置化**：所有权重为可配置参数（载体见待确认点 2），默认值参考旧 EQS（各 20 或以调优值起步）。

**与旧 EQS 的差异**：
- 去掉"未耕地/未种植"两项权重（候选集已限定活跃农田——开荒不属于本期范围）
- 新增"待重播"项（收获后闭环）
- 距离项改为显式评分项（角度差；旧版由 EQS 原生 Distance Test 承担）

### FR-4 主动奔赴

```
卫星不再只处理"轨道正下方最近格子"：
  选点产出的目标可能在轨道任意位置 → 卫星调整目标角度 → 沿轨道奔赴 → 到达 → 作业
（轨道移动机制复用现有 StartMoveToTarget/移动 Processor，无新移动逻辑）
```

### FR-5 作业时长（简单表示）

```
卫星到达目标 → 停留 N 秒（作业中）→ 执行操作 → 完成
- 时长来源：DA_FarmCell 行为定义的 Duration 字段（架构已具备，按操作类型区分）
- 本期"简单表示"：仅停留计时 + 日志/调试可视；不做动画/特效
- 作业期间：持有认领（其他卫星不可抢；玩家 High 可抢占）
```

### FR-6 认领与互斥（复用既有协议）

- 目标认领：按操作类型认领对应 Slot（Plot / Crop）
- 创建类操作（Slot 未启用时不认领直接执行——与玩家守卫同一规则）
- 玩家 High 抢占行为不变；被抢占/作业失败 → 统一重选出口（回巡航重选）

### FR-7 卫星形态：单一全能卫星

- 一种卫星类型 + 一个状态树（扩展 ST_Satellite），不做类型分化
- 状态树承载：巡航 → 选点 → 奔赴 → 作业（含时长）→ 释放 → 回巡航

## 五、非功能需求

| 项 | 要求 |
|---|---|
| 选点成本 | 单次选点遍历候选集（活跃农田，预期几十~数百格）；规模化后需评估降频/缓存 |
| 作业并发 | 多卫星并发作业不同格子（认领互斥保证）；同格互斥 |
| 数据一致性 | 状态判定以格子 Mass fragment 为权威（B 路径）；操作经 CellManager |
| 可观察性 | 日志（认领/作业/完成）；fragment 携带当前目标与操作类型（供调试与将来 HUD） |

## 七、已确认决策（v1.1）

| # | 问题 | 结论 |
|---|---|---|
| 1 | **重播的实现方式** | **B 选定**：CellManager 增加"重播"语义（允许对 Harvested 作物直接覆盖播种：重置数据、扣种子、复用播种初始化）——格子全程留在活跃农田，闭环完整 |
| 2 | 评分权重配置载体 | **A 选定**：SatelliteManager 可配结构体（蓝图细节面板） |
| 3 | 距离项形式 | **B 选定**：角度差 + 轨道平面偏离罚项 |
| 4 | 作业时长默认值 | 默认 2s（DA_FarmCell 行为定义可逐项配） |

## 八、验收标准

```
场景 1（单格全周期）：
  预置"已耕地+已播种"格子（缺水缺肥状态）→ 卫星自动完成：浇水 → 施肥 → （生长）→ 收获 → 重播
场景 2（多缺口与优先级）：
  同屏构造"杂草/虫害/缺水/成熟"混合格子 → 卫星按评分权重顺序处理（权重大者在先）
场景 3（主动奔赴）：
  活跃农田不在卫星当前角度附近 → 卫星主动调整角度奔赴目标并完成作业
场景 4（多卫星互斥）：
  多卫星共享活跃农田 → 无冲突；同格不重复作业（认领互斥 + 状态复查）
场景 5（玩家抢占）：
  卫星奔赴/作业期间玩家手动操作该格 → 玩家 High 抢占成功，卫星自动重选
```

## 九、附：旧 EQS 规则迁移对照

| 旧 EQS 组件 | 新体系对应 |
|---|---|
| `EQSGenerator_CoveredCells`（候选=轨道覆盖格子） | 候选集 = 活跃农田（主动奔赴：受角度差/轨道偏离约束） |
| `EQSTest_PlotState`（位掩码过滤） | 过滤 = 存在实际缺口（逐项判定，见 FR-1） |
| `EQSTest_PlotScore`（7 项权重） | 评分 = 状态权重（6 项，去掉耕地/种植）+ 距离项 + 待重播项 |
| EQS 查询资产（权重可调） | 权重配置（载体见待确认点 2） |
| 旧"任务队列"（BuildTaskSatelliteQueue） | 单操作循环（每轮评分选一个缺口执行，天然连续） |
