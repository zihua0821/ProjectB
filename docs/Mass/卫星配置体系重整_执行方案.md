## 三、目标形态

### 3.1 卫星配置数据资产

```
新资产：USatelliteConfigDataAsset（UPrimaryDataAsset；放置目录与命名最终按项目习惯定）
字段分组（草案——字段名待敲定，值 = 现默认值迁移）：
  · 卫星本体：Mesh / Scale / Count / AngularVelocity / bClockwise / DefaultOrbitName
  · 轨道默认：OrbitRadius(原 FallbackOrbitRadius) / ServiceDistance(原 DefaultServiceDistance)
  · 转场：RadialTransferSpeed /（HoverHeight 归属见 D6）
  · 规划：SlotMultiplier / PlanIntervalSeconds / WaitAngleLimitDeg / RebalanceRatio
         / RebalanceIntervalSeconds / SlotLeadToleranceDeg / MoveMinDeg
  · 评分：FSatelliteScoringWeights（9 字段——结构随之迁入本资产头文件；S8 裁决后可能再调形态）
  · 任务：ClaimPriority / DepartAlignToleranceDeg / SelectIntervalSeconds / TakeoffAlignToleranceDeg
         / DriftMinDurationSeconds / DriftMaxDurationSeconds / DefaultActionDuration
空资产/字段缺省策略：资产为空 → 全走硬编码默认值（现有常量的值作为兜底，保证可空运行）
```

### 3.2 FOrbitDefinition 统一

```
合并后 FOrbitDefinition（保留该名）=
  几何：OrbitName / Transform / Radius / ServiceDistance
  + 运行时：SatelliteCount / AngularVelocity / bClockwise / VisualColor / CoverageColor
· 删除 FRuntimeOrbitData（全库引用替换：Manager / SmartObjectManager / PC / Widget / OrbitCoverageVisual）
· 定义位置从 OrbitManagerComponent.h 迁出 → 迁入卫星域头文件（见 D2）
· CalculateOrbitAngleFromCell 签名简化：(CellWorldTransform, OrbitTransform) 双 Transform——
  任务侧临时构造（Tasks L337-339）删除
```

### 3.3 旧数据链退役

```
· 退役 UOrbitManagerComponent（.h/.cpp 删除）+ PlanetActor 摘除创建与接口实现
  （APlanetActor::GetOrbitData_Implementation → 回落 IPlanetInterface 默认实现）
· 删 PlanetConfigDataAsset::OrbitDefinitions 字段 + include 清理
· BuildRuntimeOrbits 简化：删除资产读取分支——直接构造【默认初始轨道】（单轨 Default）
  （"不需要用资产定义轨道，放一个默认的就好"——用户口径；默认参数来自卫星配置资产/硬编码兜底）
· PlanetInterface::GetOrbitData 保留与否见 D7
```
