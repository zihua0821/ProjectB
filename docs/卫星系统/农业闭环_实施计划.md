## 一、架构数据流

```
玩家播种（Crop Slot 启用）
      ↓ 意图委托（复用既有事件 OnCellSlotStateChanged）
SatelliteManager 维护「活跃农田」集合（TSet<FIntPoint>）
      ↓
卫星 StateTree（巡航态）→ 选点：遍历活跃农田 → 逐格评分 → 取最高分
      ↓ 按操作类型认领对应 Slot（Plot/Crop）→ 写 TargetEditMode + 目标角度
奔赴（复用 StartMoveToTarget / 移动 Processor）→ 到达（Paused）
      ↓
作业（EnterState 记录开始时间 → Tick 倒计时 → 到点执行操作）→ 释放 → 回巡航
```

**执行链全景（实施后）**：
```
SatelliteStateTreeTick  心跳信号
      ↓
MassStateTree Processor  Cruise → MoveToTarget → Execute → Cruise
      ↓
SatelliteOrbitMovement   角度推进（含主动奔赴）
      ↓
SatelliteRenderSync      ISM 渲染
```

## 二、关键设计

### 2.1 候选集维护（零新埋点）

`SatelliteManagerComponent` 订阅 `CellManager->OnCellSlotStateChanged`：

```
SlotIndex==1 && bEnabled  → ActiveFarmlandCoords.Add(Coords)   // 播种：入集合
SlotIndex==1 && !bEnabled → ActiveFarmlandCoords.Remove(Coords) // 移除作物：出集合
```

- 与 `SmartObjectManager` 的订阅互不干扰（各自独立处理）
- 格子生命周期全程正确：播种入 → 收获（含 Harvested）保持 → 重播保持 → 移除作物出

### 2.2 选点评分（EQS 迁移版）

```cpp
// 对每个候选格子（活跃农田）：
// ① 轨道覆盖硬过滤（几何判定，替代旧物理 Overlap）：
//    格子中心到轨道平面的垂直距离 ≤ 半格高 × CoverageHalfThicknessScale
//    CellHeight = Radius × 纬度步长弧度（与旧 UpdateOrbitCoveredCoords 同源公式）
if (!IsCellInOrbitCoverage(CellTransform, OrbitNormal, PlanetConfig, 系数)) continue;
// ② 缺口评估（缺什么补什么；各缺口按权重计分取最高——权重即优先级）
if (!EvaluateCellNeeds(PlotState, CropState, Weights, EditMode, NeedScore)) continue;
// ③ 评分 = 缺口分 − 角度差 × DistanceWeight（FindDeltaAngleDegrees）
// ④ 最高分（> MinScoreThreshold）→ 按操作类型认领对应 Slot（GetSlotIndexForEditMode）
```

**缺口判定（阈值化——"缺什么补什么"语义）**：

| 缺口 | 判定 | 操作 |
|---|---|---|
| 杂草 | `EPlotState::WeedInfested` | UnWeed |
| 虫害 | `EPlotState::PestInfested` | UnPest |
| 成熟 | `CropGrowthStage == Mature` | Harvest |
| 已收获 | `CropGrowthStage == Harvested` | Replant（新） |
| 缺水 | `MoisturePercentage < MoistureThreshold` | Wet |
| 缺肥 | `FertilityPercentage < FertilityThreshold` | Fertilize |

**节流**：仅"巡航态"选点；每 0.2s 最多一次（Task InstanceData 记 LastSelectTime）。

### 2.3 作业时长（InstanceData 实现）

```
FSatelliteExecuteActionTask（已实现）：
  EnterState：读行为定义 Duration → InstanceData.ActionStartTime/ActionDuration → Running
  Tick：     倒计时未到 → Running；到点 → ExecuteFarmAction → 释放认领 → 清 fragment → Succeeded
```

- Duration 来源：`USmartObjectSubsystem::GetBehaviorDefinition<UFarmActionBehaviorBase>(ClaimHandle)->Duration`（模板重载；无认领/无定义时用缺省 2s）
- InstanceData 字段：`ActionStartTime`（double）+ `ActionDuration`（float）

### 2.4 重播（CellManager 内实现，无新接口）

```
PlantCrop 内重播分支（实施定稿，比原计划更小改动）：
  ① 存在性检查放宽：已有作物且非 Harvested → 拒绝；Harvested → 进入重播
  ② CropID：重播沿用格子已有作物的 CropID（同类型作物），忽略传入名（AI 入口传空名）
  ③ Fragment：仅首次播种添加；重播沿用既有 Fragment
  ④ 初始化命令统一：StateData.Reset() + LastRenderedStage=None + Timer 清零 + Quality.Reset()
  ⑤ 扣种子（与播种一致）；Crop Slot 广播保持启用（格子全程留在活跃农田）
  ⑥ AI 入口 ExecuteFarmAction(EditMode, Coords)：不依赖玩家上下文
```

> 微调说明：原计划的"新增 ReplantCrop 接口 + 提取 PushCropInitCommand"在实施时被上面的小改动取代（决策 B 原文即"复用 PlantCrop 逻辑"）——CellManager 接口只新增 AI 入口。

### 2.5 数据结构扩展

```cpp
// SatelliteManagerComponent 配置（UPROPERTY 蓝图可配）
USTRUCT(FSatelliteScoringWeights)
{
    float HarvestWeight = 20.f;      // 成熟待收
    float ReplantWeight = 15.f;      // 待重播
    float WeedWeight = 30.f;         // 杂草
    float PestWeight = 30.f;         // 虫害
    float MoistureWeight = 20.f;     // 缺水（旧 EQS 默认）
    float FertilityWeight = 20.f;    // 缺肥（旧 EQS 默认）
    float DistanceWeight = 0.5f;     // 距离（角度差，度）
    float CoverageHalfThicknessScale = 1.f; // 轨道覆盖半厚系数（1.0=旧语义：±半格高）
    float MoistureThreshold = 0.7f;  // 缺水阈值
    float FertilityThreshold = 0.7f; // 缺肥阈值
    float MinScoreThreshold = 1.f;   // 最低选择分
};

FMassSatelliteTaskFragment：
    + EEditMode TargetEditMode（要执行的操作；UENUM 类型，调试直接显示枚举名）

FMassSatelliteSharedFragment：
    + TObjectPtr<USatelliteManagerComponent> SatelliteManager（集合+权重宿主）

SatelliteManagerComponent：
    + TSet<FIntPoint> ActiveFarmlandCoords
    + FSatelliteScoringWeights ScoringWeights（UPROPERTY EditDefaultsOnly）
    + GetActiveFarmlandCoords() / GetScoringWeights()
```

## 四、运行前提与风险

| 项 | 说明 |
|---|---|
| 生长系统 | 缺水/缺肥需"生长消耗"在运行才会出现；若未运行，用预置工具构造状态测试（不阻塞实现） |
| 选点成本 | 每 0.2s × 卫星数 × 候选集大小（预期几十~数百）；规模化后评估（降频/缓存/需求表） |
| 认领覆盖 | 创建类操作（Slot 未启用）不认领直接执行——与玩家守卫同规则；水/肥/草/虫/收获/重播均对应已启用 Slot（正常认领） |
| 玩家抢占 | 作业期间玩家 High 抢占 → 卫星作业完成时操作可能已无意义（状态复查兜底）→ 释放回巡航 |
| 轨道偏离 | 目标格可能远离轨道平面——偏离罚项抑制过远目标；极端情况下卫星"够不着"的格子自然不会被选中（权重调优） |

## 五、与旧 EQS 的差异（迁移说明）

| 旧 | 新 | 说明 |
|---|---|---|
| CoveredCoords 候选（物理 Overlap 预计算） | 活跃农田集合（事件维护） | 免物理、免预计算；语义更聚焦（只关心有作物的田） |
| 7 项权重（含未耕地/未种植） | 6 项权重（去掉开荒相关） | 候选集已限定活跃农田 |
| 距离由 EQS Distance Test 承担 | 显式评分项（角度差 + 偏离罚） | 与轨道移动物理一致 |
| —（无） | 待重播项 | 新增收获后闭环 |
