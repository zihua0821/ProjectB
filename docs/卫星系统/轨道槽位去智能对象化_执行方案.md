## 一、目标

```
轨道槽位：智能对象实例（引擎 API）→【自建轻量槽池】（项目数据结构）
· 删除引擎依赖：4 API（Create/Destroy/MarkClaimed/MarkFree）+ 每轨 N×K 实例（现状 250/轨）
  + 微查询注册绕路 + 智能对象资产要求
· 重建链 O(1)：数组重置 + 代际++（替代现状 O(N×K) 逐个销毁/创建）
· 位置语义统一（引擎位置"撒谎"议题永久消失——M-2 S3 结论）
· 边界：格子智能对象【保留零改动】（其用法正当：空间注册/荷载/行为/启停）
· 轨道槽专用句柄 FOrbitSlotHandle（取代 FSmartObjectClaimHandle 在轨道侧的全部使用）
```

## 三、目标形态

### 3.1 数据结构（自建槽池）

```
FOrbitSlotHandle（新句柄——轨道槽专用）
  · OrbitName（FName——穿透面改动最小；身份稳定，与现状"按名查询"同源）
  · SlotIndex（int32）
  · Generation（uint32——重建该轨时全池++：旧句柄全失效，防幽灵认领·ISM 前车之鉴）
  · IsValid() + operator== + GetTypeHash（可作比较/容器键）

USatelliteSlotPool（【10-10 裁定：独立 UObject 类——定义/实现与 SatelliteManagerComponent 同文件】）
  · 单对象管全部轨道：内部 TMap<FName, 每轨槽数据>（每轨数据体 = 几何五件 + 三平行数组）：
      几何：OrbitTransform / OrbitRadius / AngularVelocity / bClockwise / CurrentPhaseDeg
      TArray<bool>   bClaimed           // 占用状态（GT 帧序内单线程——无需原子）
      TArray<uint32> Generations        // 每槽代际（认领返回时快照；重建时 ++）
      TArray<FVector> SlotWorldPositions // 推进时更新（查询/渲染/判据同源数据）
  · 槽数 = SatelliteCount × K（注册时定格）；实例由 SatelliteManager 持有（UPROPERTY 子对象）
```

### 3.2 接口（形状沿用现状——调用方近零改动）

```
RegisterOrbitSlots(Orbits, K) / RegisterSingleOrbitSlots(Orbit, K)（重建该轨 = 清空 + 代际++ + 重建数组）
UnregisterOrbitSlots(OrbitName)（删轨路径）
UpdateOrbitSlots(dt)（相位推进 + 位置缓存——帧序 GT 驱动不变）
GetOrbitSlotCount / GetOrbitSlotPhase（快照承重——签名不变）
TryClaimOrbitSlot(OrbitName, SlotIndex) → FOrbitSlotHandle（GT 单线程：查 bClaimed → 置位 → 返回带 Gen 句柄）
ReleaseOrbitSlot(Handle)（校验 Gen → 清 bClaimed——与格子释放【分离】）
ResolveSlotIndexByClaim / GetOrbitSlotWorldPositionByClaim / GetOrbitSlotPhaseByClaim（校验 Gen 后按 SlotIndex 查）
```

### 3.3 归属与宿主

```
槽池从 SmartObjectManager 移出——【10-10 裁定：独立 UObject 类 USatelliteSlotPool，
  定义/实现与 SatelliteManagerComponent 同文件（.h 内类定义 + .cpp 内实现）；实例由 Manager 持有】
· SlotSync 处理器：改调 SatelliteManager->UpdateOrbitSlots(dt)（一行改动；帧序/组结构零改动——M-1 红利）
· 任务侧 Shared：槽查询改经 Shared.SatelliteManager（已含该指针）；SmartObjectManager 指针用途收窄为格子认领
· 调试绘制：槽位球随池迁移 + 开关化（CVar，默认关——§七 联动裁定）
· 资产退役：DA_OrbitSlot（OrbitSlotDefinition）不再需要（用户清理）
```

### 3.4 联动确认

```
· 渲染取位优先级不变（覆盖位置 → 槽位点 → 账面相位）——数据源换池
· 规划器发单三件套（认领目标槽/释放旧槽/冻结显示覆盖）——改调池接口，逻辑零变
· 格子认领（M-4/N10 面）不受影响；N10 先行（D5）已解耦同文件顺序
```
