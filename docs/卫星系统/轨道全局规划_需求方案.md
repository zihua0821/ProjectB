> **状态**：**v1.0 —— 定稿**（全部决策已确认，无待抉择项；参数见第六节）
> **日期**：2026-09-28　**分支**：`MassCrop`
> **定位**：承接《卫星离轨作业》之后的演化——把"轨道分布均匀"从"演化结果/事后修正"提升为**显式目标**，并以**群体决策**（全局、确定性）统一管理"落点分配 + 巡航均匀化"。

> **v1.1 实施修订摘要（2026-09-29，运行期收敛）**——正文 v1.0 保留为"设计与决策快照"；以下为实施中的修订（完整复盘见《轨道全局规划_运行期问题复盘.md》）：
> 1. **决策宿主**：由"卫星管理器组件 Tick"改为 **Mass 帧序内的规划处理器**（`USatelliteOrbitPlanProcessor`；节拍 1s 不变）——消除跨驱动源时序
> 2. **阶段②求解重写**："试算锚 + 全体对齐网格" → **"消除过近"**（与最近邻居 ≥ 有效线免动；只动挤对中可动一方；无动源静默）＋独立 **5s** 节流
> 3. **漂移倾向**：候选择选"**前移优先**；必须后移时保底绝对速度 0.25ω（不停住）"；时长上限 4.5 → **6s**
> 4. **中断语义**：漂移探测到工作 → **当场认领** → 统一"✓→Depart"（原"条件转移区分去向"因跨帧竞态废弃；滑完经 DepartWait"无目标"自愈）
> 5. **选点修正**（现实施行的补充）：距离改"单向轴行程 + 提前量"；扫描跳过"已被认领"格
> 6. **容差**：触发线合理区间 0.6~0.8（0.95 离散不可满足）；起飞判据改角度域（1.5°）

## 一、背景与目标

### 1.1 背景（问题的由来）

```
现状回轨链：Work 完成 → 悬停在格子上空 → 选空槽（窗口 δ∈[−45°,+2°]）→ 等槽位转到悬停投影处 → 起飞
问题根因：K=1（槽数=星数）时唯一空槽=自己让出的，若其"刚过投影"需等近一整圈：
         等待均值 ~18s、最坏 ~36s（ω=10°/s；锯齿：T_让槽 ≈ 整圈的整数倍时归零，超出一点立刻跳回）
演化问题：若按倍数扩槽（K≥2）但不加约束，"回轨落位=窗口内最近空槽"
         会使星群向任务区方位漂移（连片），消耗均匀性、退化等待
```

"均匀分布的卫星轨道运行模式"是本次讨论回归的**最初需求**；两条病根——**候选太少（等待长尾）**与**分布演化失控（连片）**——都归结为"缺少一个以轨道为整体的全局决策"。

### 1.2 目标

1. **分布均匀**：农田集中等扰动下，在轨星座的相位分布长期保持均匀（不连片、不聚集失控）
2. **等待受控**：回轨等待消除"等一整圈"的长尾（均匀优先的落点分配 + 必要时巡航均匀化）
3. **决策/执行分层**：群体决策（全局、确定性、可重算）与个体执行（六状态机职责不变）清晰分层
4. **体系一致**：转场数学（极坐标同步）、认领协议、单一事实源等既有约定全部延续，不引入第二事实源

### 1.3 非目标（当前明确不做）

| 项 | 说明 |
|---|---|
| 档 B：废槽连续体系 | 槽位保留（含认领/渲染/调试），不做"连续相位 + 自建互斥" |
| 变轨式漂移 | "抬起-连续滑行-收回"的物理感漂移（中间段不停）列为**未来优化项**（见 R6） |
| 多轨协同 | 每轨独立规划，轨道之间无耦合 |
| 转场数学改动 | 离轨/回轨的极坐标同步转移不动 |
| 任务分配全局化 | 选点/任务分配保持现状（评分+认领），列为未来项 |

## 二、术语约定

```
槽位        ：轨道上的离散工位（智能对象，随轨道以 ω 公转）；槽数 = 卫星数 × K
占位        ：某星"应当处于"的槽（权威来源 = 星的槽认领句柄；在途星=目标槽句柄）
在途星      ：已领取"漂移指令"、正在滑向目标槽的星（占位按其目标槽计——"在途当已到"）
待返星      ：作业完成、悬停在格子上空、等待分配回轨槽的星（无槽句柄）
群体决策    ：由卫星管理器在固定间隔执行的"抄账 → 求解 → 发单"周期（确定性、无状态、无旧账）
滚动节拍    ：固定间隔滚动决策（不等待执行完成；在途状态计入快照，天然消解等待）
漂移        ：星在轨道上从槽 A 平滑到槽 B（仅切向——同轨道"加速/减速"，无变轨）
```

## 三、需求项（已确认）

### R1　槽位倍数扩容（K≥2）

```
槽数 = 卫星数 × 5（K=5，已确认 2026-09-28）
· 槽网格加密 = 全局决策的"候选自由度"（K=1 时全局规划几乎空转：唯一空槽无选择）
· 初始分配：星 i ↔ 槽 i×K（保持起步均匀）
· 语义修订：槽位从"一星一位的工位"演进为"带富余的车位池"（文档与调试口径同步更新）
```

### R2　群体决策层（轻量、无独立状态机）

```
· 宿主：USatelliteManagerComponent::TickComponent（固定间隔节流；不新增独立状态机/状态树）
· 节拍：滚动决策——到点即"抄账 → 求解 → 发单"，不等执行完成（在途计入快照视为已到占位）
· 性质（三条硬约束）：
    ① 确定性：同一份快照 → 同一份计划（任何调用点/调用次数结果一致）
    ② 无状态：不缓存旧账；每次从实体数据重算（规避"双推进源"类结构缺陷）
    ③ 不落第二事实：计划为派生物，消费即弃；占位地图统一由"槽认领句柄"推导
· 快照的"在途当已到"：星的占位 = 其槽句柄所指的槽（在途星=目标槽；离轨/作业/待回星无句柄=不占位）
```

### R3　全局落点分配（回轨选槽改为"读指令"）

```
· 待返星的目标槽由全局决策统一分配（不再"各自窗口内选最近"）
· 选择规则（乙案·已确认）：先划掉"等待角 > 45°"的候选；剩下取"插入后最小相邻间距最大"者；平局取等待角小者
· 决策即认领（预认领）：发单三件套 = 认领目标槽 + 释放旧槽 + 冻结显示覆盖
    （冻结防止"句柄切换帧"渲染瞬移；细节见执行方案）
· 时机判定保留：起飞仍等"目标槽实时位置与悬停投影重合"（δ0 补偿保持零偏差落位）
```

### R4　巡航均匀化漂移（仅同轨道滑行）

```
· 形态：同轨道"加速前移 / 减速后移"滑行——加速=比轨道快、前移追赶目标位；减速=比轨道慢、让目标位迎上来；滑动速度差 = 1 倍轨道速度（滑行速度最高 2 倍轨道速度）；后移不得减速到倒车。半径/垂直不变（复用转场参数方程）
· 时长：滑动时长 = 位移 ÷ 速度差，夹在 [2 秒, 4.5 秒]（大位移不磨蹭、小位移自动放慢）
· 位移范围：3° 以下不动（不值当）、45° 以上不干（与等待上限统一为 45°）
· 触发：只由群体决策发单（星的巡航任务消费指令）
· 状态归属（已确认）：独立状态 Drift（数据/任务/运动模式独立）；StateTree 中作为 Cruise 的子状态组织
· 约束（防撞·合并版，已确认）：任何两段路线（含正在走的）只要区间重叠，后发的那条推迟下一轮；新路线也不得穿过他星占位
· 中断：任务优先——以"实测显示位置"为离轨起点直接离轨（同源原则，零跳变），旧槽新槽认领随之释放，回轨时重新分配
· 速度曲线：线性（与转场一致）；"缓入缓出"列为未来修饰项
```

### R5　释放时机修正（独立修正项）

```
· 格子认领（全量 ClaimHandles）的释放点：由"回轨到达（Return Tick）"前移至"回轨起飞瞬间（Return EnterState）"
· 效果：格子互斥期缩短一个飞行时长 T（≈2s）；"单点释放"原则不变（仅位置变更）
· 口径备注：轨道槽位的"让槽"现状已是离轨起飞瞬间，无此问题
```

### R6　未来优化项（仅记录，当前不实施）

```
① 变轨式漂移：抬起 → 连续滑行（不停）→ 收回 的三段式物理感漂移；相位修正放在滑行段
   （升级路径：只替换"执行器的运动形态"，决策层接口不变）
② 任务分配全局化：把选点/任务分配并入全局决策（合成总调度）
③ δ0 掠入：起飞容差放宽（用可控的"斜插"换取等待进一步缩短）
```

## 五、验收标准

```
① 分布：农田集中场景长跑（多轮任务循环）后，星分布无连片（最小相邻间距 ≥ 约定下限）或收敛到均匀间隔（容差内）
② 等待：回轨"等一整圈"的长尾消除（等待分布对比现状：均值/最坏显著下降，实测确认幅度）
③ 漂移质量：漂移全程不穿越他星（路径校验生效）；起止无瞬移（覆盖位置连续）
④ 确定性：同一快照任意次数调用 → 计划一致（可测试）；无"谁先算/何时算"的结果差异
⑤ 中断：漂移全阶段（含冻结帧）接任务 → 以显示位置为起点直接离轨，无跳变
⑥ 无回归：单星全流程（收获→5s→重播→回轨）、六状态机、格子链路、认领协议全部无回归
⑦ 性能：规划开销可忽略（节流间隔 + N 小；实测确认）
```

## 七、决策记录（对话已确认）

```
① 大方向 = 档 A：全局决策 + 槽位执行（废槽连续体系不采纳）
② 群体决策 = 轻量：放卫星管理器 Tick；滚动节拍（固定间隔）；在途星当"已到占位"算

④ 变轨式漂移 = 未来优化项（中间段不停的设计已记录）
⑤ 释放时机修正 = 格子认领释放点前移至"回轨起飞瞬间"
⑥ 均匀分布 = 最初需求与显式目标（一切机制服务于它）

⑧ 漂移状态 = 独立状态 Drift（数据/任务独立）；StateTree 中作为 Cruise 的子状态组织

⑫ 参数统一：等待上限 = 位移上限 = 45°；滑动速度差 = 1 倍轨道速度；时长夹 [2, 4.5] 秒
⑬ 在途星一单到底（不改目的地）；仅任务优先可打断
```
