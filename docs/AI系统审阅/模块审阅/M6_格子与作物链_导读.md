## 三、农业闭环（生命周期链）

```
播种：PlantCrop L838 → 写作物 fragment（阶段=Seed）→ 认领 Crop Slot
      → 【L949 广播 (1, true)】→ SmartObject 启用 Crop Slot + Satellite 加活跃农田
生长：CropGrowthProcessor::Execute L27（白名单可暂停）：
      L63 无作物清理 → L73 Harvested 计时 → L79 种子双缺停长 → L85 品质累加
      → L103 成熟停长 → L110 生长速率（缺水/缺肥=0；过水/烧苗/草/虫 乘子）
      → L124 生长计时 → L139 阶段转换（Seed→Seedling→Mature）
      → L153【成熟入队】MatureCropQueue.Enqueue（Deferred 命令，GT 执行）
成熟：ProcessMatureQueue L43（定时器）→ OnAutoHarvest L67 → HarvestCrop L952
收获：HarvestCrop L952 → 阶段=Harvested + 计时清零 → 【L1016 广播 (1, false)】→ 槽禁用+出集合
重播：CollectCellGaps（M-1 侧）判 Harvested 停留 ≥ ReplantDelay(5s) → 产生 PlantCrop 缺口
      → 卫星执行 PlantCrop → 循环闭合
耕地：PlowLand L656 →【L681 广播 (0, true)】；RemoveLand L684 →【L709 广播 (0, false)】
```

**意图委托**（`FOnCellSlotStateChanged`，.h L17）：4 广播点（L681/L709/L949/L1016）——
两个订阅者：SmartObjectManager（Slot 启停）+ SatelliteManager（活跃农田集合维护）。
