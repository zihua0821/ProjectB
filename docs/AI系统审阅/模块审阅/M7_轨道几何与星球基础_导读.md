## 二、函数地图与四类语义（A 组清理后的现状）

```
① 坐标转换
   L35 ConvertLocationToCellCoord    世界/本地位置 → 格子坐标（反算）
② 轨道位置（极坐标核心）
   L74 ComputeOrbitWorldPosition     参数方程：OrbitTransform 内 (Radius, AngleDeg) → 世界点 ★
   L99 ComputeOrbitHoverPoint        悬停点：格子中心方向 ×(R + HoverHeight)——含平面外分量 ★
   L106 DecomposeToOrbitPlane        世界点 → (θ, 平面内半径, 垂直分量) ★（任务链判据/起点反算）
③ 覆盖判定（平面带模型——与轨道半径无关）
   L81 ComputeDistanceToOrbitPlane   点到轨道平面距离
   L86 IsPointInOrbitCoverage        距离 ≤ ServiceDistance（选点/可视化共用）★
④ 角度辅助
   L9  CalculateOrbitAngleFromCell   格子变换 → 轨道平面内方位角（调用面走查核对——C1 关联）
   L91 NormalizeAngleDegrees360      归一化 [0,360)（任务链/规划器共用——10-06 编译修复提取为公共函数）
```

**关键几何约定**（散落在注释中，值得集中记忆）：
- **理想球面几何**：作业几何一律以理想球面 R 为准（CellOffsetZ 抬升只影响渲染，不影响作业）——C4 观察项，注释修订阶段补声明；
- **角度域约定**：θ 单位度、[0,360) 归一；`FindDeltaAngleDegrees` 处理跨源求差（易错点 #13）；
- **方向规约**：进出参数方程的一律是"相位增量"（含 dir 语义——易错点 #20）；
- **覆盖 = 平面带**：距离判定不依赖轨道半径（B2 修正口径——旧注释"管∩球面"已过时）。
