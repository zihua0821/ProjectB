## 二、双系统结构（核心认知）

```
┌─ 格子 Slot（作业席位）────────────────────────────────────┐
│ 资产：DA_FarmCell（Slot[0]=Plot / Slot[1]=Crop）           │
│ 注册：Initialize → 委托 → TickComponent 分批（5000/帧）    │
│ 映射：CoordToEntry：坐标 → {对象句柄, Plot 句柄, Crop 句柄} │
│ 认领：TryClaimSlot（Normal/High 优先级——玩家可抢）        │
│ 账本：ClaimLedger[SlotIndex][坐标] = 当前句柄——幽灵识别    │
└──────────────────────────────────────────────────────────┘
┌─ 轨道槽位（空间席位）──────────────────────────────────────┐
│ 资产：DA_OrbitSlot（单 Slot 实例化 N 份）                   │
│ 注册：RegisterSingleOrbitSlots（每轨 N = 卫星数 × K）      │
│ 数据：FOrbitSlotEntry = 轨道几何(4) + 实例三数组            │
│       {ObjectHandles, SlotWorldPositions, SlotHandles}     │
│ 推进：UpdateOrbitSlots（槽 i 相位 = CurrentPhaseDeg+360i/N）│
│ 认领：TryClaimOrbitSlot（卫星唯一认领方）                  │
└──────────────────────────────────────────────────────────┘
共性：都是"智能对象实例 + Slot 句柄 + MarkSlotAsClaimed"协议；组件是唯一认领入口
```

## 三、轨道查询体系（"认领前索引、认领后句柄"）

```
【索引入口】（认领前用）：
  GetOrbitSlotCount  ——规划快照/槽网格规模
  GetOrbitSlotPhase  ——规划快照读"槽 0 基准相位"（承重）
【句柄入口】（认领后唯一入口——避免双字段不同步）：
  GetOrbitSlotWorldPositionByClaim（渲染②/任务链/漂移发单读旧槽点）
       └─ 内联：ResolveSlotIndexByClaim（句柄反查索引）→ 直查 SlotWorldPositions
  GetOrbitSlotPhaseByClaim（任务链相位判据）
  ResolveSlotIndexByClaim（调试/日志可读性——未找到 -1）
```

## 四、数据流

```
注册流：Initialize → CellManager 委托注册 → [Tick 分批] RegisterCell → CoordToEntry
启停流：CellManager 业务 → 委托回调 HandleCellSlotStateChanged → SetSlotEnabled
认领流（格子）：任务 SelectTarget → TryClaimSlot → 账本写入 → 引擎 MarkSlotAsClaimed
                释放：Return 起飞瞬间（全量账本）→ ReleaseClaim
认领流（轨道）：创建初始认领 / 规划器发单（旧释放+新认领）/ 中断释放
推进流：M-2 Slot 处理器（GT）→ UpdateOrbitSlots → 缓存刷新 → 同帧渲染②读到最新
查询流：渲染②（每帧 ByClaim）/ 任务链（判据/起点）/ 规划快照（Count+Phase）
```
