## ③ 关键实现与决策点

### 3.1 相位统一与单状态（P1/P2 埋雷的正式了结）

```cpp
// 之前（P1~P5）：CurrentAngle + TargetAngle（角度对）+ ESatelliteMoveState 三态（兼到达信号）
// 现在：（b4f3548）
float VirtualPhase;         // 唯一相位字段——"始终按 ω 推进：巡航位置基准与回轨依据"
ESatelliteState State;      // 唯一状态字段——各任务在 EnterState 写入
```
- **"唯一"二字是本次重构的核心道德**：一个运动量一个字段、一个状态一个字段——P1 的"双枚举耦合"、P2 的"MoveState 双职责"在此终结
- 注：到达信号不再挂在状态上（MoveState==Paused 模式废弃），改为**各任务自行判定**（Approach 判 Alpha≥1；DepartWait 判相位差）

### 3.2 作业队列机制（多缺口连续作业）

```cpp
// 选点与队列构建【同源】重构（b4f3548）：
CollectCellGaps(格) → 按分数降序的缺口全列表
  选点取首项（最高分）→ 决策依据；队列取全列表 → WorkQueue（一次出勤按序做完全部）
ClaimHandles 与 WorkQueue 一一对应（同 Slot 多项共享句柄）
```
- **"选点与队列同源"**（同一评分函数两用）——避免了"选的活和干的活不一致"的错位
- 队列机制让"一格多缺口"一次出勤解决——出勤成本摊薄

### 3.3 六状态机任务链（格局定型）

| 任务 | 状态 | 职责 |
|---|---|---|
| SelectTarget | Cruise | 节流选点（评分）→ 认领 → Depart |
| DepartWait | Depart | 等离轨时机（初版"最近点"→ 演进为提前量点） |
| Approach | Approach | 飞往悬停点（初版贝塞尔 → 极坐标） |
| ExecuteAction | Work | 悬停作业（队列倒计时执行） |
| ReturnWait | AwaitReturn | 等回轨时机（初版"最近点"→ 槽位重合判据） |
| Return | Return | 飞回轨道（初版贝塞尔 → 极坐标） |

- 这套任务表一直沿用（P7 只加了 Drift + 判据升级）——**重构的格局稳定**

### 3.4 首版贝塞尔转场与其缺陷（Bug 复盘 1/2/3）

### 3.5 极坐标同步转场（方案 2，6b9e0bb 定稿——终态模型）

```cpp
// 一参数方程统天下（离轨/回轨/漂移同构）：
pos(α) = ComputeOrbitWorldPosition(r(α), θ(α)) + n × v(α)
  θ(α) = θ_start + Δθ·α；r/v 线性插值
// 核心性质（一次构造消掉三类问题）：
  切向角速度恒 = ω（同步即预测——不需要预测运动目标）
  半径/方位是绝对量插值（不需要"相对量约束"）
  θ 单调推进（不需要方向判据）
// 时长 T = sqrt(Δr² + Δv²) / v_r（RadialTransferSpeed 配置统一——离轨/回轨共用）
```
- **"同步即预测"**：落点自动对准运动中的槽位（无需动态改终点）

### 3.6 轨道槽位系统（6b9e0bb 初版 N=卫星数）

```
RegisterOrbitSlots：每轨 N 槽（智能对象实例，DA_OrbitSlot）；槽 i 相位 = CurrentPhase + 360×i/N
槽位条目（FOrbitSlotEntry）：轨道几何 + CurrentPhaseDeg + 槽句柄/世界位置（索引对齐）
查询三件：GetOrbitSlotWorldPosition / GetOrbitSlotPhase / ResolveSlotIndexByClaim
按句柄三件：GetOrbitSlot*ByClaim（已认领后的唯一查询入口——"避免索引与句柄双字段不同步"）
UpdateOrbitSlots：相位推进（每帧；槽位与卫星同速旋转）+ 同步内部缓存位置
```
- **"槽位 = 卫星的轨道锚点"（方案 B）**：渲染取位优先级确立为 ①覆盖位置 ②归属槽世界点 ③账面相位点（无槽回退）——修复"青球恒定落后"（复盘 Bug4：两条独立推进线）
- **ByClaim 单一事实源**：fragment 只留 `SlotClaimHandle`，槽索引不落字段（复盘 Bug7 的修复）

### 3.7 判据与起点同源（复盘 Bug5/Bug6 的修复）

```
DepartWait 判据：显示位置（槽位世界点）与提前量点的【相位差】——"判据参考物必须与玩家看到的东西同源"
Approach 起点：起飞瞬间的【实测显示位置】（不再公式反推）——"从哪儿起飞就从哪儿算"
Return 落点：θ_delta = ω·T·dir + δ0（δ0 = 槽位相位 − 悬停投影方位）——
  "目标在运动时，落点以【目标相位】为基准"（同速偏差显式补偿，零偏差入轨）
```

### 3.8 垂直分量与两分量模型（复盘 Bug8——跨子空间修复）

```
悬停点（格子法线 × (R + h)）可能在轨道平面外；轨迹点曾被约束在平面内 → 端点对不上
修复：轨迹 = 平面内(θ, r) + 法线偏移(v)；DecomposeToOrbitPlane 统一分解；
      frag 增加 PhaseVerticalStart/End；时长用合成跨度 sqrt(Δr² + Δv²)
```

### 3.9 账本修正（同步出队 → 全量保留）

```cpp
// b4f3548 初版：ClaimHandles"逐项出队时同步移除"——回轨时清单已空 → 释放无处寻（Slot 泄漏）
// 6b9e0bb 修正：“全量保留——出队只消耗 WorkQueue，本数组作为出勤账本保留至真实回轨到达统一释放”
//   （当前项句柄 = ClaimHandles[已消费数]；已消费数 = 总长 − WorkQueue 剩余长度）
```
- 注：释放时机此时是"回轨**到达**"——P7 再前移到"回轨**起飞瞬间**"（互斥期缩短一个飞行时长；交接文档 R5）
