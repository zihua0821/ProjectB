## ③ 关键实现与决策点

### 3.1 选点从"最近格子"升级为"评分制"（SelectTarget 大改）

**旧版（P1/P2）**：位置反推最近一格 → 只看成熟 → 认领。
**新版（a14fdf1）**：
```cpp
// 1. 节流：每 0.2s 选一次（IConstSelectIntervalSeconds），不再每帧遍历
// 2. 遍历【活跃农田集合】（不再扫全网格）：
//    2.1 轨道覆盖硬过滤：IsCellInOrbitCoverage（几何判定——见 3.2）
//    2.2 直读格子 fragment（B 路径）
//    2.3 缺口评估 EvaluateCellNeeds：六种缺口按权重取最高
//    2.4 距离扣分：Score = NeedScore − |FindDeltaAngleDegrees(当前角, 目标角)| × DistanceWeight
// 3. 最高分 < MinScoreThreshold → 继续巡航（不接单的门槛从这天开始）
// 4. 按操作类型认领对应 Slot（GetSlotIndexForEditMode——P2 建的映射表首次投入实战）
```

**决策点**：
- **"缺口评估（缺什么补什么）+ 权重可配"**（`FSatelliteScoringWeights` 蓝图可配：六种权重 + 两阈值 + 距离权重 + 最低分）——明确注释"**EQS 迁移版**"：旧 AI 的 EQS 评分思路从引擎 EQS 搬到代码（这是后来"选点迁移 EQS"反向预留的伏笔: 现在代码化的评分是旧 EQS 的移植，未来再考虑回归 EQS 框架）
- **活跃农田集合**（`TSet<FIntPoint>`）：由 CellManager 的委托 `OnCellSlotStateChanged` 维护（Crop Slot 启用=播种/重播成功入集合；禁用=移除出集合）——"只扫潜在目标"的第一层性能优化
- ⚠️ **距离扣分用"无向角度差"**（`AngularDistanceDegrees` = 绝对值）——**"无向角距"的诞生点**：此时卫星会选"身后近的目标"（在旧 MoveToTarget 逻辑下等一圈才能到）——当时不是问题（移动模型简单），但在 P6 的转场模型下成为 bug（P7 修正为"单向轴行程 + 提前量"，见 P7 报告的根因链）
- 支持"**不适用认领的操作直接执行**"（SlotIndex<0 时 ClaimHandle 为 Invalid）——为后续扩展留的口子

### 3.2 轨道覆盖判定 v1：半格高模型（后来的模型更替点）

```cpp
// IsCellInOrbitCoverage（本提交版）：
const float LatStep = (MaxLat - MinLat) / (NumLat - 1);
const float CellHeight = Radius × DegreesToRadians(LatStep);     // 格子物理高度
const FVector CellCenter = CellTransform.GetLocation().GetSafeNormal() × Radius;   // 投影回球面
const float PlaneDistance = |Dot(CellCenter, OrbitNormal)|;
return PlaneDistance <= CellHeight × 0.5f × HalfThicknessScale;  // 默认 ±半格高
```
- **语义**："轨道平面上下各半格高"（注释明说"旧语义"——从旧系统继承的覆盖模型）
- 系数 `CoverageHalfThicknessScale`（可配，1.0 = 旧语义）——服务距离的雏形（**P5 改为独立的 `ServiceDistance`**，见 P5 报告 3.2）
- 备注：注释"**几何替代旧物理 Overlap**"——旧系统用物理 Overlap 集合判定覆盖，本提交改为纯数学判定（性能与确定性双收）

### 3.3 执行任务：Harvest → ExecuteAction（作业时长机制）

```cpp
EnterState：读行为定义取 Duration（USmartObjectSubsystem->GetBehaviorDefinition<UFarmActionBehaviorBase>；
            无认领/无定义 → DefaultActionDuration=2s）→ 记录 ActionStartTime → Running
Tick：倒计时未到 → Running（作业停留——卫星"悬停干活"的观感来源）
      倒计时到 → ExecuteFarmAction(目标操作, 目标格) → 释放认领（创建类无句柄则跳过）→ 清理 → Succeeded
```
- **作业时长**数据来自智能对象行为定义（`UFarmActionBehaviorBase::Duration`，DA_FarmCell 配置）——"每种农活耗时不同"的表现层数据接线
- 注释记录了一个引擎坑：`GetBehaviorDefinition<T>` 为非 const 成员函数（Subsystem 指针不可加 const）——后来的置顶易错点之一

### 3.4 配套：CellManager 的 AI 入口与重播链增强

- **`ExecuteFarmAction`（AI 专用入口）**：注释明确"与 HandleLeftMouseClicked 的差异：播种不使用玩家选中的作物——重播自动沿用格子已有作物的 CropID（同类型作物）"——**AI/玩家双入口分立**（终态保留此分工）
- **PlantCrop 重播增强**：重播时整体重置（`CropStateData.Reset()` + Timer 清零 + Quality Reset）——避免继承上一轮状态位；"重播=复活链"的基础
- fragment：新增 `TargetEditMode`（`TEnumAsByte<EEditMode>` 包装 unscoped 枚举以满足 UHT——注释记录了该 UHT 规则）
