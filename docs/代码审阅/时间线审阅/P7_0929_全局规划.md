## ③ 关键实现与决策点

### 3.1 K=5 槽位扩容（决策：给全局决策留自由度）

```cpp
// OrbitSlotMultiplier = 5（配置）——槽数 = 卫星数 × K
RegisterOrbitSlots(RuntimeOrbits, OrbitSlotMultiplier);
OrbitFragment.SlotClaimHandle = TryClaimOrbitSlot(OrbitName, Index * OrbitSlotMultiplier, ...);
// 初始认领 i×K：相位恰好均分——起步布局与 K=1 时一致（向后兼容的锚定）
```
- **为什么 K=5**：K=1 时槽位与卫星一一对应、回轨只能回自己的槽——群体决策无空间可调度；K=5 让"落座/整理"有候选余量（决策自由度）

### 3.2 群体决策三件套（架构：抄账 / 求解 / 发单）

```cpp
TickOrbitPlanning（1s 节流；由 PlanProcessor 在 Mass 帧序内驱动）：
  CollectOrbitSnapshots：同一帧一口气读完（"同一张照片"）
    · 占位 = 槽句柄（在途/返航星=目标槽——"在途当已到"，高招：发单后账目立即自洽）
    · 待返星带悬停点；漂移星带路径弧段（防撞禁区）
  BuildOrbitPlan（每轨独立；**静态纯函数**：只读快照+参数、无状态、确定性——同一快照必得同一计划）
  DispatchOrbitPlan：认领目标槽 + 写回句柄（失败/已占位跳过；下轮快照自然复核）
```
- **纯函数求解**是此设计的灵魂：无状态、可推演、可重放；"滚动节拍不等待执行完成"（在途按目标槽计）——避免了"等执行完成才能再决策"的耦合

### 3.3 落座乙案（等待角过滤 + 最大化最小间距）

```
候选 = 空槽中"等待角 ≤ 45°"者（ComputeSlotWaitAngleDeg：槽还要转多少度到悬停点正下方）
择选 = 插入后最小相邻间距最大 → 平局等待角小 → 再平局小索引（确定性排序链）
```
- 双目标（别再挤 + 别等太久）在约束内求解——"乙案"相对"甲案（纯等待角最小）"更抗堆积

### 3.4 漂移机制（同轨道加速/减速，无变轨）

```
发单三件套：认领目标槽 + 释放旧槽 + 冻结显示覆盖（防"句柄切换帧"渲染瞬移）
时长 = |Δs| / 滑动速率上限，夹 [2,6] s；位移范围 [3°,45°]
前移优先（P2 决策）+ 后移保底速度 0.25ω（消除"停住被穿越"）；后移上限 6s（不倒车）
消费路径：规划器置 bDriftRequested → 评估器（纯数据源）→ "Tick时+条件"转移 → Drift 任务消费
中断：漂移中探测（节流）发现值得接的工作 → 当场认领 → 释放目标槽 → 清覆盖 → 统一"✓→Depart"
```

### 3.5 均匀化（阶段②）：从"追求等距"到"消除过近"（运行期重写）

```
触发：最小相邻间距 < 均匀间距 × 触发线（0.6~0.8）
重写后（复盘 #3/#4）：
  · "与最近邻居 ≥ 有效线 → 免动"——防止对已达标星产出伪位移（自维持死循环根治）
  · "只动挤对中可动的一方"——不可动源（在途/待返）不再触发永动触发条件
  · 前移优先 + 后移保底速度；独立 5s 节流（决策节拍 vs 漂移时长匹配）
防撞（合并版）：新弧段 vs 在途漂移弧段/本轮已发弧段，重叠即跳过（下轮再议）
```

### 3.6 选点修正：无向角距 → 单向轴行程 + 提前量（复盘 #1）

```
旧：Score = NeedScore − |FindDeltaAngleDegrees(当前, 目标)| × 权重       // 身后点"看着近"→ 误选
新：ForwardDeg = 到"提前量点（目标方位 − ω·T）"的正向角距 [0,360)      // 身后 = 最远（等一圈）
   递进：T 逐格精算（平面内+垂直合成跨度 / v_r，与 Approach 同源）——"提前量"不是近似
```
- 修正了"地块被掠过不执行"的历史根因（交接文档早期遗留项之一）

### 3.7 中断卡死根治（R-B，复盘 #8——"修竞态不如删环节"）

```
问题：条件转移（bWorkClaimed）跨帧竞态（50% 成功率）→ 中断送达失败 → 回 Cruise → 本格已被自己认领
      → 跳过 → 长真空（36s/180s）
根治：取消条件区分——Drift 成功统一 → Depart；
      滑完（无认领）→ DepartWait 首帧"无目标"Failed → 回 Cruise（1~2 帧自愈）
      + 复用分支（已有有效认领 → 直接 Succeeded）兜底异常回访
效果：中断送达 4/4（13~19ms）；reuse 兜底 0 次
```

### 3.8 帧序收编（复盘 #10/#11——"所有运行时驱动收编进 Mass 帧序"）

```
显式帧序：规划（PlanProcessor 新建）→ 槽推进（并入 Movement：先槽后星，同帧同序）
        → 卫星相位推进 → 渲染同步 → 心跳 → 状态树任务
组件 Tick 退出运行时驱动（SmartObjectManager 的槽推进、Manager 的规划全改由处理器驱动）
```
- **"跨驱动源时序=事故温床"**：三个驱动源（组件 Tick / Mass 处理器 / 状态树）碰同一批数据的教训

### 3.9 释放点前移（R5/Step 0：格子认领互斥期缩短）

```
释放时机：回轨到达 → 【回轨起飞瞬间】（Return::EnterState 唯一释放点；同句柄去重）
——互斥期缩短一个飞行时长 T；账本（全量保留）在该时刻统一清算
```
