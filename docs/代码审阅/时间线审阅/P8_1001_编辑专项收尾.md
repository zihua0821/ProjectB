## ③ 关键实现与决策点

### 3.1 选定暂停系统（`USimulationControlSubsystem`——"只持状态 + 白名单宏"）

```cpp
// 新建子系统：只持有"仿真是否暂停"一个状态；输入 SetSimulationPaused(bool)
// 白名单挂载宏（跨体系通用，一行仪式）：
#define SIMULATION_PAUSE_RETURN(World) \
    if (USimulationControlSubsystem::IsSimulationPaused(World)) { return; }

// 白名单四成员（tick 入口挂宏）：
//   USatelliteStateTreeTickProcessor（心跳——行为总闸）
//   USatelliteOrbitPlanProcessor（规划）
//   USatelliteOrbitMovementProcessor（槽推进 + 卫星相位）
//   UCropGrowthProcessor（作物生长）
// 不参与（默认运行）：视觉同步 / 渲染同步 / 玩家相机 UI / 昼夜
```
- **"白名单式选定暂停"**的设计：编辑时要停的是"世界演化"（卫星行为 + 作物生长），而玩家飞行、UI、可视化照常——**暂停粒度按"演化链"而非"整个世界"**（比 TimeDilation/SetPaused 精细）
- 子系统只持状态、参与者用宏自检——**零基类约束、零继承污染**（跨体系通用）

### 3.2 StateTree 时间基准重置（防"恢复即瞬移"）

```cpp
ResetSatelliteStateTreeTimeBase（ExitOrbitEditMode 中、解除暂停之前调用）：
  遍历卫星实体 → FMassStateTreeInstanceFragment->LastUpdateTimeInSeconds = Now
// 背景：Mass StateTree 任务 dt = 墙钟差（MassStateTreeProcessors）——
// 暂停期心跳停发（无 tick），恢复后第一帧 dt = 整个暂停窗口 → PhaseElapsed 跃增 → 瞬移
```
- **"暂停窗口不计入任务 dt"**——引擎"时间补偿设计"的坑（易错点 #18）

### 3.3 重建链三修复（P0 根治——R4 冲突的核心）

```
① 销毁前归还认领（DestroySatellitesForOrbit）：
   · 格子认领：Task.ClaimHandles 全量账本（同 Slot 多项共享句柄——【星内去重】释放；
     重复释放会被引擎拒绝并报 Error：账本清理幂等、引擎 MarkSlotAsFree 不幂等）
   · 轨道槽认领：SlotClaimHandle
   ——"认领是借，销毁前必还"；保证重建后"账本/引擎/槽位"三处无残留
② 旧槽实例显式销毁（UnregisterOrbitSlots）：
   ——"资源生命周期：实例不随条目移除消失——必须显式销毁"（SmartObjectSubsystem->DestroySmartObject）
③ 认领失败 Warning：Initial slot claim failed（结构异常可见化——"无槽星"信号）
```
- **根因回顾（P5-E3 的收口）**：P5 建立 DestroyAllSatellites 时未梳理"销毁时的资源归还"——P6 加入长事务认领后成为真实泄漏源，P8 补齐

### 3.4 按轨重建（编辑影响面最小化）

```
ApplyOrbitChangesForOrbit(轨道名)：① 销毁该轨旧卫星（含归还）→ ② RegisterSingleOrbitSlots（先注销旧槽再建新）
                                    → ③ CreateSatellitesForOrbit（初始认领新槽）+ 注册渲染 + 入列
其他轨道零触碰（星/槽/句柄全原样）
ApplyOrbitChanges（全量）保留为调试入口（= 逐轨循环）
AddOrbit/RemoveOrbit 同步改造（增=只建新轨；删=只毁该轨 + UnregisterOrbitSlots）
```
- **R4 冲突的根因**：全量重建会连带重置其他正在作业的轨道——"编辑只影响当前轨"才符合编辑者的心智模型

### 3.5 实时应用链（提交 → 落地 → 重建；拖动节流）

```
① 提交链（Slate 提交回调顺序坑）：OnValueCommitted【先于】OnValueChanged（SSpinBox::CommitValue）——
   "提交即消费数据"的回调必须自己先落地本次值（不能依赖值变化回调先执行）
② 拖动节流重建：值变化 → RequestThrottledRebuild（最多 0.2s 一次）；松手/回车提交回调做最终落实
③ 删 Apply 按钮与旧入口（ApplyOrbitChangesToSatellites → CommitOrbitChanges(轨道名)，按轨语义）
```
- **"所见即所得"**：从"预览 + 手动应用"改为"提交即重建"——交互直观性换取"每轨重建成本需可控"（按轨重建 3.4 先行落地是前提）
