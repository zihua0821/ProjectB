## 二、结构/职责

### 2.1 数据结构账本（字段 → 写者 → 读者）

**FMassOrbitFragment**（核心运动状态；L38-83）：

| 字段 | 写者 | 读者 |
|---|---|---|
| `OrbitName` | Manager 创建时 | 全链（查轨道/槽位） |
| `VirtualPhase` | **四写**：Movement 每帧推进（+ω·dt·dir）/ 创建均分（360i/N）/ 到达归位（←槽相位）/ 漂移中断（←滑行相位） | 渲染③（无槽兜底）/ DepartWait③ / Approach 起点兜底 |
| `AngularVelocity` / `bClockwise` | Manager 创建时（轨道参数拷贝） | Movement（推进方向与速度） |
| `State` | **各任务 EnterState**（唯一状态字段） | 快照（规划）/ 渲染 / 任务链 |
| `bOverrideLocation` + `OverrideLocation` | Approach/Work/Return/Drift 每帧写 | 渲染①（最高优先级位置源） |
| `SlotClaimHandle` | 创建初始认领 / 规划器发单切换 / 中断释放（清空） | 渲染② / 槽位查询 ByClaim / 规划快照 |
| `bDriftRequested` | 规划器发单置位 | 评估器 → 状态树转移；**Drift EnterState 消费即清** |

**FMassSatelliteTaskFragment**（跨任务上下文；L156-228）——任务间的"工作台"：

| 字段组 | 写者 | 读者/消耗 |
|---|---|---|
| `TargetCoord` / `TargetEditMode` | SelectTarget | Approach（算悬停点）/ DepartWait；失权清理 |
| `ClaimHandle`（格子槽，兼容字段=首项） | SelectTarget | Work 执行；**真实账本见下** |
| `WorkQueue` / `ClaimHandles` | SelectTarget（BuildCellWorkQueue + 一次认领） | Work **只出队 WorkQueue**；ClaimHandles 全量保留=出勤账本，**Return 起飞瞬间统一释放** |
| `Phase*` 轨迹参数（7 个） | Approach/Return/Drift 各自 EnterState 一次算好 | 各自 Tick 每帧参数方程求值 |
| `PhaseElapsed` / `PhaseDuration` | 同上 | Tick 推进 Alpha = Elapsed/Duration |
| `DriftInterruptTimeSeconds` | 漂移中断帧 | DepartWait 送达探针（首帧记录延迟并清零） |

**FSatelliteTag**（空 Tag，查询过滤）/ **FMassSatelliteSharedFragment**（ConstShared 按值去重：轨道几何 + Mesh + 三个组件指针——任务访问 UObject 的唯一通道；L110-149）。

### 2.2 任务职责（声明注释已高度准确，此处提炼一句）

| 任务类 | 状态 | 一句话（EnterState / Tick 分工） |
|---|---|---|
| SelectTarget | Cruise | Tick 节流 0.2s 选点：CollectCellGaps 评分 → 认领格子槽 → 写目标+队列 |
| DepartWait | Depart | Tick 纯等待+判据（相位差 ≤1.5°）；失权检查；不控制运动 |
| Approach | Approach | Enter 算轨迹+开覆盖+让槽；Tick 参数方程+所有权检查 |
| ExecuteAction | Work | Enter 写悬停点+开首项；Tick 倒计时→执行→出队→空则 Succeeded |
| ReturnWait | AwaitReturn | Tick 等"槽位实时位置与悬停投影重合"（≤3°）——槽位由群体决策写回 |
| Return | Return | Enter 算落点(δ0 补偿)+**释放全量格子认领**；Tick 飞行+到达归位清覆盖 |
| Drift | Drift | Enter 算 Δs/时长+消费请求；Tick 飞行+节流"掠过作业"探测；到达归位 |
| DriftRequestEvaluator | (挂 Cruise) | 每帧把 `bDriftRequested` 照进实例数据（纯数据 → 供条件转移） |

## 三、数据流（四条主线）

```
① 相位流（时间轴）：
   Movement(worker,每帧) ──+ω·dt·dir──▶ VirtualPhase
   恰在"到达/中断"两刻被任务重写（归位/滑行）——"影子追实体"
   └─兜底读取：渲染③ / DepartWait③ / Approach 起点

② 轨道槽句柄流（空间席位）：
   创建(初始认领 i×K) ──▶ SlotClaimHandle ──▶ 渲染②(槽世界点)
   规划器发单：旧槽释放 + 新槽认领 + 冻结显示（三件套）
   漂移中断：释放目标槽（清句柄）→ 无槽窗口由相位流①兜底

③ 覆盖位置流（飞行/作业实况）：
   Approach/Work/Return/Drift 每帧写 OverrideLocation ──▶ 渲染①（优先级最高）
   清除时机：到达/回轨落点（各任务 Tick 尾部）

④ 作业队列流（格子账本）：
   CollectCellGaps(评分降序) ──▶ WorkQueue + ClaimHandles(一一对应)
   Work：只消耗 WorkQueue（当前项=ClaimHandles[总长−剩余]）
   Return::EnterState：ClaimHandles 全量释放（唯一释放点）
```

## 四、调用链：六状态机（转移以 ST_Satellite 资产为准，此处按注释归纳）

```
Cruise ──SelectTarget Succeeded──▶ Depart ──DepartWait Succeeded(相位对齐)──▶ Approach
   │                                  │(Failed:失权)                              │
   │ Evaluator: bDriftRequested                                              Succeeded(到达悬停)
   ▼                                                                             ▼
 Drift ══(统一去向)══▶ Depart                                           Work ──Succeeded(队列空)──▶ AwaitReturn
   │                              (中断:释放目标槽+回写滑行相位)              │(Failed:失权)         │
   │到达/接单                                                               Cruise            ReturnWait Succeeded
   ▼                                                                                             ▼
 Depart(接单) / 滑完经 DepartWait"无目标"自愈回 Cruise                                      Return ──Succeeded──▶ Cruise
```

**关键规则**（易错点引用）：
- 任务"瞬时事实"不跨帧表达（#12）——漂移中断统一"→Depart"，无目标自愈；
- 失权统一走 `HandleOwnershipLost`（L158）——清本地任务数据、返回 Failed；
- 状态全部在 EnterState 写入（唯一字段不双写）。
