## 二、生命周期链（创建）

```
Initialize（L173）
  ├─ 绑定 PlanetActor / 注册 CellManager 意图委托（活跃农田集合）
  ├─ BuildRuntimeOrbits（L230）：PlanetConfig->OrbitDefinitions → FRuntimeOrbitData（空则兜底）
  └─ CreateAllSatellites（L276）
       └─ 逐轨 CreateSatellitesForOrbit（L298）：
            ① 组 Shared（轨道几何 + Mesh + 三组件指针，按值去重）
            ② 建原型（4 Fragment + FSatelliteTag + 可选 StateTree 实例）
            ③ BatchCreateEntities
            ④ 逐星初值：OrbitName / VirtualPhase 均分(360i/N) / ω / 方向
            ⑤ 初始认领：TryClaimOrbitSlot(i × OrbitSlotMultiplier)（失败带 Warning）
       └─ RegisterRenderInstances（L390）：BatchAddInstances（GroupKey）→ 回写 InstanceId
```

## 三、编辑链（按轨重建——编辑交互的正式路径）

```
UpdateOrbitData（L586）：只落数据 + 广播可视化（不触卫星——须重建才生效）
AddOrbit（L603）：校验重名/None → ServiceDistance 兜底 → Add → ApplyOrbitChangesForOrbit → 广播
RemoveOrbit（L632）：移除数据 → DestroySatellitesForOrbit → UnregisterOrbitSlots → 广播

ApplyOrbitChangesForOrbit（L522）——三步顺序是关键：
  ① DestroySatellitesForOrbit（L428）——先撤人再拆设施：
       筛选目标轨 → 【归还一切认领】（格子：Task 两域句柄 Plot/Crop；轨道槽：SlotClaimHandle）
       → BatchDestroyEntities → 其余轨道实体原样保留
  ② RegisterSingleOrbitSlots——重建该轨槽位（新槽供初始认领）
  ③ CreateSatellitesForOrbit + RegisterRenderInstances——重建该轨星与渲染
（全量重建能力 = 逐轨循环此函数；原全量入口 M3 已删）
```

## 四、规划层（群体决策三件——"抄账 → 求解 → 发单"）

```
TickOrbitPlanning（L672）：1s 节流（OrbitPlanIntervalSeconds）
  → CollectOrbitSnapshots（L710）：同一帧一口气读完全部卫星（"同一张照片"）
       按轨分组；占位=句柄所指槽（在途当已到）；在途漂移星记录弧段（防撞禁区）；
       可动星标记（Cruise + 占位 + 无请求）；悬浮点（待返星）
  → BuildOrbitPlan（L787，静态纯函数；同一快照必得同一计划——确定性无状态）
       L794 占位集合 → L805 待返星按序 → L817 乙案落座（等待角≤45° → 插入后最小间距最大）
       → L857 阶段②均匀化"消除过近"（可动星升序 L888；择选判据 L920；独立 5s 节流）
       → L1002 防撞（合并版弧重叠检查——与在途弧 + 本轮已发弧）
       输出 FOrbitPlan（落座指令 / 漂移指令）
  → DispatchOrbitPlan（L1043）：
       L1071 落座：认领目标槽 + 写回句柄（待返星原无槽）
       L1092 漂移三件套：认领目标槽 → 写单（句柄=B + bDriftRequested + 冻结显示 OverrideLocation）
             → 释放旧槽
```

**配置面**（.h 私有 UPROPERTY）：ScoringWeights / MinScoreThreshold / SatelliteMesh+Scale /
RadialTransferSpeed / OrbitSlotMultiplier / OrbitPlanIntervalSeconds / OrbitPlanWaitAngleLimitDeg /
OrbitPlanRebalanceRatio / OrbitRebalanceIntervalSeconds。
