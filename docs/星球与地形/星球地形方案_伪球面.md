# 星球地形方案 - 伪球面

> 决策日期：2026-03-11
> 方案状态：已确定

---

## 决策结论

采用**伪球面**方案，而非真实球面地形。

---

## 为什么选择伪球面

| 维度 | 伪球面 | 真实球面 |
|------|--------|----------|
| 现有代码复用 | 90%+ | 50% |
| 开发周期 | 2周 | 2-3个月 |
| 地块编辑体验 | 简单直观 | 复杂（曲率问题） |
| 风险 | 低 | 高 |
| 玩家体验差异 | 几乎无 | 微小 |

**核心原因**：
- 保留现有平面地块系统，避免重写核心
- 玩家局部区域感知不到曲率差异
- 快速验证玩法优先于技术炫技
- 参考案例：《星露谷物语》《动物森友会》均为平面地形

---

## 核心原理

```
实际地形：平面网格（保留现有代码）
    ↓
视觉效果：Shader弯曲远处地形
    ↓
镜头控制：限制视野，雾效遮挡边界
    ↓
玩家感知："我在一个星球表面"
```

---

## 架构分层

### 1. 数据层（完全保留）
- 地块系统：平面坐标 (x, y)
- 作物系统：生长逻辑不变
- 工具系统：交互逻辑不变
- 保存系统：数据格式不变

### 2. 表现层（新增）
- **Shader弯曲**：远处地形向下弯曲，模拟球面
- **镜头限制**：最大高度、最大视野距离
- **地平线雾效**：遮挡远处边界
- **天空盒**：星空 + 其他星球代理

### 3. 切换层（新增）
- **星系图**：展示真正的球体星球（视觉模型）
- **视角切换**：点击星球后镜头下落到平面游玩视角

---

## 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 虚拟星球半径 | 1000-5000米 | 决定弯曲程度，越大越平 |
| 最大视野距离 | 500米 | 超过此距离用雾效遮挡 |
| 弯曲公式 | y = -k * x² | k = 1/(2R) |
| 镜头最低高度 | 1米 | 贴近地面 |
| 镜头最高高度 | 30米 | 俯瞰视角 |

## 技术要点

### Shader实现方式
- **推荐**：UE5材质蓝图 + World Position Offset
- **难度**：低（无需手写HLSL）
- **动态更新**：C++每帧更新PlayerPosition和BendAmount参数

### 镜头控制
- 软限制：不硬截断，用雾效密度过渡
- 玩家只能看到"星球表面"局部区域
- 远处自动弯曲消失，看不到地图边界

### 星系图与游玩视角
```
星系图视角：展示真正的球体星球
      ↓ 点击自己的星球
镜头动画：拉近、球体占满屏幕
      ↓ 瞬间切换
游玩视角：平面地形（玩家感知不到切换）
```

## 风险与应对

| 风险 | 应对 |
|------|------|
| 弯曲效果不自然 | 可调参数BendAmount，找到舒适值 |
| 玩家发现是平面 | 限制镜头，雾效遮挡，实际很难发现 |
| 性能问题 | Shader在GPU运行，几乎无CPU开销 |
